# C++ 核心课程大纲

## 模块一：封装  
类与对象的核心机制 — 8 节课

- **L01** 类与对象基础 (`class` / `struct`)
- **L02** 访问控制与封装原则 (`public` / `private`)
- **L03** 构造函数详解 (`ctor` / 初始化列表)
- **L04** 析构函数与对象生命周期 (`~dtor` / 顺序)
- **L05** 拷贝构造函数与深拷贝 (`T(const T&)`)
- **L06** `this` 指针与 `const` 成员函数 (`this` / `const`)
- **L07** 运算符重载 (`operator+`)
- **L08** `static` 成员与友元 (`static` / `friend`)

---

## 模块二：继承与多态  
OOP 最核心的扩展机制 — 7 节课

- **L09** 单继承基础 (`class B : A`)
- **L10** 多继承与菱形继承问题 (多继承 / 二义性)
- **L11** 虚继承 (`virtual Base`)
- **L12** 虚函数与 vtable 原理 (`virtual` / vtable)
- **L13** 纯虚函数与抽象类 (`= 0` / 接口)
- **L14** 虚析构函数与多态内存安全 (`virtual ~Base()`)
- **L15** RTTI 与 `dynamic_cast` (`dynamic_cast`)

---

## 模块三：现代 C++ 基础  
C++11/14/17 核心新特性 — 7 节课

- **L16** 右值引用基础 (`T&&` / 左右值)
- **L17** 移动构造与移动赋值 (`std::move`)
- **L18** 三/五/零法则 (Rule of 3/5/0)
- **L19** Lambda 表达式 (`[&] (x) { }`)
- **L20** `auto` 类型推导与 `decltype` (`auto` / `decltype`)
- **L21** `std::function` 与 `std::bind` (`function<>`)
- **L22** 其他 C++11 新特性集锦 (`nullptr` / `constexpr`)

---

## 模块四：模板与泛型编程  
编译期的魔法 — 6 节课

- **L23** 函数模板 (`template<T>`)
- **L24** 类模板 (`template class`)
- **L25** 模板全特化与偏特化 (`template<>`)
- **L26** 可变参数模板 (`typename... Args`)
- **L27** SFINAE 与 `std::enable_if` (`enable_if`)
- **L28** C++20 Concepts 与 `if constexpr` (`requires` / `concept`)

---

## 模块五：STL 与智能指针  
现代 C++ 工程实战核心 — 8 节课

- **L29** 序列容器：`vector` / `list` / `deque`
- **L30** 有序关联容器：`map` / `set`
- **L31** 无序容器：`unordered_map` / `set`
- **L32** 迭代器：分类、使用与失效 (`iterator`)
- **L33** STL 常用算法 (`algorithm`)
- **L34** 智能指针：`unique_ptr` 与 `shared_ptr` (所有权模型)
- **L35** `weak_ptr` 与循环引用 (`weak_ptr` / `lock()`)
- **L36** RAII 原则与资源管理 (RAII)
