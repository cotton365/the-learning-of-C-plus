## 一、this 指针

### 1.1 它是什么

你在前几课写过这样的代码：

```cpp
class Circle {
public:
    double radius;
    double area() {
        return 3.14159 * radius * radius;
    }
};

Circle c1, c2;
c1.radius = 3.0;
c2.radius = 5.0;
c1.area();  // 返回 c1 的面积，不是 c2 的
```

`area()` 函数里直接用了 `radius`，但 `c1` 和 `c2` 各有自己的 `radius`——当你调用 `c1.area()` 时，函数怎么知道用的是哪一个 `radius`？

答案是：**编译器悄悄给每个成员函数传入了一个隐藏参数——指向当前对象的指针**，这就是 `this`。

你写的：

```cpp
double area() {
    return 3.14159 * radius * radius;
}
```

编译器实际处理成类似这样：

```cpp
double area(Circle* this) {
    return 3.14159 * this->radius * this->radius;
}
```

调用 `c1.area()` 时，编译器传入的是 `&c1`；调用 `c2.area()` 时，传入的是 `&c2`。`this` 就是这个"当前对象的地址"。

> `this` 是一个**指针常量**（`T* const`）——指针本身不可修改（不能让 `this` 指向别的对象），但指向的对象内容可以修改（除非是 `const` 成员函数，见第二节）。`this` 不需要你声明，它由编译器自动提供。

### 1.2 用途一：解决同名冲突

最常见的使用场景：成员变量和函数参数同名时，用 `this->` 明确指定哪个是成员变量。

```cpp
class Person {
public:
    std::string name;
    int age;

    // 参数名和成员变量名相同
    void setInfo(std::string name, int age) {
        // 直接写 name = name; 是错的——赋值给自己，成员变量不变
        this->name = name;   // this->name 是成员变量，name 是参数
        this->age  = age;
    }
};
```

当然，你也可以给参数起不同的名字（比如 `_name`、`newName`）来避免冲突，这是个人风格问题。但理解 `this->` 解决冲突的方式是必须掌握的。

### 1.3 用途二：返回当前对象引用，实现链式调用

`this` 是指向当前对象的指针，`*this` 就是当前对象本身。如果成员函数的返回值是 `类型&`，并且 `return *this`，调用者就能在一条语句里连续调用多个函数——这叫**链式调用（method chaining）**。

```cpp
class Builder {
public:
    std::string result;

    Builder& addText(const std::string& s) {
        result += s;
        return *this;   // 返回当前对象的引用
    }

    Builder& addNewline() {
        result += "\n";
        return *this;
    }

    void print() {
        std::cout << result;
    }
};

int main() {
    Builder b;
    b.addText("Hello").addText(", ").addText("World").addNewline().print();
    //  ^^^^^^^^^^^^^^^^ 每次返回 *this，下一个函数继续在同一个对象上调用
    return 0;
}
```

**链式调用的本质**：每次调用后返回的是同一个对象的引用，所以点号后面可以继续调用下一个函数。如果返回的是值（不是引用），每次都会产生一个新对象，链式调用就断了。

你在标准库里见过的 `std::cout << a << b << c` 就是这种模式——`<<` 每次都返回 `cout` 本身的引用。

### 1.4 用途三：在函数中传递自身

有时候需要把当前对象的指针传给另一个函数或保存起来：

```cpp
class Node {
public:
    Node* next = nullptr;

    void linkTo(Node* other) {
        this->next = other;
    }

    Node* getSelf() {
        return this;   // 返回当前对象的地址
    }
};
```

## 二、const 成员函数

> 这是本课的核心重点，需要仔细理解。

### 2.1 为什么需要 const 成员函数

假设你写了一个 `Circle` 类，有一个 `area()` 函数：

```cpp
class Circle {
public:
    double radius;
    double area() { return 3.14159 * radius * radius; }
};
```

现在有人把一个圆作为常量传进来：

```cpp
void printArea(const Circle& c) {
    std::cout << c.area();  // 编译错误！
}
```

编译器报错，原因是：`c` 是 `const` 的，但 `area()` 是普通函数——**编译器无法确认 `area()` 会不会修改 `c` 的内容**，所以它拒绝调用。

解决方式：在函数声明和定义后面加 `const`，向编译器做出承诺——"这个函数不会修改任何成员变量"：

```cpp
class Circle {
public:
    double radius;
    double area() const {   // ← 加在括号后、大括号前
        return 3.14159 * radius * radius;
    }
};
```

现在 `printArea(const Circle& c)` 里调用 `c.area()` 就没问题了。

### 2.2 const 成员函数的语法

```cpp
class Foo {
public:
    int value;

    // 声明和定义在类内：括号后加 const
    int getValue() const { return value; }

    // 声明在类内，定义在类外
    std::string toString() const;   // 类内声明也要加 const
};

// 类外定义也要加 const
std::string Foo::toString() const {
    return std::to_string(value);
}
```

**两处都要加**：类内声明处和类外定义处，缺一不可。

### 2.3 const 成员函数的限制与本质

`const` 成员函数里，`this` 的类型从 `T* const` 变成了 `const T* const`——指向的对象也变成只读的了。因此：

**在 `const` 成员函数里，你不能：**

```cpp
class Counter {
public:
    int count = 0;

    void increment() const {
        count++;   // 编译错误：不能修改成员变量
    }

    void reset() const {
        count = 0; // 编译错误：同上
    }
};
```

**可以调用其他 `const` 成员函数，但不能调用非 `const` 成员函数：**

```cpp
class Foo {
public:
    int x = 0;

    void modify() { x = 10; }      // 普通函数
    int read() const { return x; } // const 函数

    void doWork() const {
        int v = read();   // ✓ 可以：read() 是 const 的
        modify();         // ✗ 不可以：modify() 是非 const 的
    }
};
```

### 2.4 const 对象

用 `const` 修饰的对象，**只能调用 `const` 成员函数**：

```cpp
class Player {
public:
    std::string name;
    int score = 0;

    void addScore(int n) { score += n; }        // 非 const
    std::string getName() const { return name; } // const
};

const Player p{"Alice", 100};
p.getName();    // ✓ getName() 是 const 的
p.addScore(10); // ✗ 编译错误：p 是 const 对象，不能调用非 const 函数
```

**常见出现场景**：

```cpp
// const 引用传参——函数内部只能调用 const 成员函数
void display(const Player& p) {
    std::cout << p.getName();  // 只有 const 函数可以被调用
}
```

实际写代码时，**凡是"不改变对象状态"的函数，都应当加 `const`**。这不是可有可无的风格选项，而是正确性的保障——如果你忘了加，别人就无法把你的对象作为 `const` 引用传递，或者无法用 `const` 对象调用你的函数。

### 2.5 const 与非 const 的重载

同一个函数名，可以同时存在 `const` 和非 `const` 两个版本，构成重载。编译器根据对象是否是 `const` 来决定调用哪个：

```cpp
class MyString {
    char* data;
public:
    // 非 const 版本：返回可修改的引用
    char& at(int index) {
        return data[index];
    }

    // const 版本：返回只读引用
    const char& at(int index) const {
        return data[index];
    }
};

MyString s;
s.at(0) = 'A';          // 调用非 const 版本，可以赋值

const MyString cs = s;
char c = cs.at(0);      // 调用 const 版本，只读
// cs.at(0) = 'B';      // 错误：const 版本返回 const 引用，不可赋值
```

这个模式在标准库容器里随处可见，比如 `std::vector` 的 `operator[]` 就有这两个版本。

## 三、mutable 关键字

### 3.1 打破 const 的限制

有时候有一个成员变量，它不代表对象的"有意义的状态"，只是一个实现细节——比如缓存、调试计数器、互斥锁。即使在 `const` 成员函数里，你也希望能修改它。

`mutable` 关键字就是为此而生：被 `mutable` 修饰的成员变量，在 `const` 成员函数里也可以被修改。

```cpp
class ExpensiveCalc {
public:
    double input;
    mutable double cachedResult = 0.0;  // mutable：即使在 const 函数里也可修改
    mutable bool cacheValid = false;

    double compute() const {
        if (!cacheValid) {
            // 模拟复杂计算
            cachedResult = input * input * 3.14;
            cacheValid = true;            // ← 修改 mutable 成员，合法
        }
        return cachedResult;
    }
};
```

从调用者的角度，`compute()` 是 `const` 的，对象的"逻辑状态"（`input`）没有改变——只是内部的缓存被更新了。这是 `mutable` 最典型的合法用途：**缓存（lazy evaluation）**。

### 3.2 ⚠️ 谨慎使用 mutable

`mutable` 是一个逃生舱，不是日常工具。滥用它会破坏 `const` 的语义，让阅读代码的人产生困惑——他们看到 `const` 函数，默认认为对象不会改变，如果你用 `mutable` 悄悄修改了重要状态，就是在撒谎。

**合理的 `mutable` 场景**：
- 缓存计算结果（如上例）
- 调试用的调用计数器
- 线程同步用的 `std::mutex`

**不应该用 `mutable` 的场景**：
- 你只是懒得把函数改成非 `const` 的
- 函数实际上在改变对象的逻辑状态，却想对外"假装"自己是 `const`

## 四、this 与 const 的结合

把两节内容放在一起看，`this` 的类型在不同场景下是这样的：

| 函数类型 | `this` 的类型 | 含义 |
|---|---|---|
| 普通成员函数 | `T* const` | 指针不可变，指向内容可修改 |
| `const` 成员函数 | `const T* const` | 指针不可变，指向内容也不可修改 |

链式调用结合 `const` 时要注意：如果函数是 `const` 的，返回 `*this` 的引用类型也必须是 `const T&`：

```cpp
class Printer {
public:
    std::string content;

    Printer& write(const std::string& s) {
        content += s;
        return *this;   // 返回 Printer&，因为函数修改了对象
    }

    const Printer& show() const {
        std::cout << content << std::endl;
        return *this;   // 返回 const Printer&，因为函数是 const 的
    }
};

Printer p;
p.write("Hello").write(" World").show();
```

## 五、注意事项汇总

### ⚠️ static 成员函数没有 this

`static` 成员函数不属于任何对象，没有 `this` 指针，也不能加 `const`：

```cpp
class Util {
public:
    static int add(int a, int b) {
        // 这里没有 this
        return a + b;
    }
    // static int add(int a, int b) const {}  // 编译错误
};
```

### ⚠️ const 成员函数只约束成员变量，不约束局部变量

```cpp
void foo() const {
    int localVar = 42;
    localVar = 100;   // ✓ 没问题，局部变量不受 const 约束
    this->memberVar = 100; // ✗ 不行，成员变量受约束
}
```

### ⚠️ 指针成员变量的 const 陷阱

`const` 成员函数防止的是修改**指针本身**，但如果成员是一个指针，指针指向的数据仍然可以被修改——这是一个容易踩的坑：

```cpp
class Container {
public:
    int* data;

    void setValue(int v) const {
        // this->data = new int(v);  // ✗ 不行：不能修改指针本身
        *data = v;                  // ✓ 合法！修改的是指针指向的内容，不是指针
    }
};
```

这意味着 `const` 成员函数并不能完全保证"对象内部的数据不变"——如果你的类持有指针，需要额外注意。

### ⚠️ 忘记在类外定义时加 const

```cpp
class Foo {
    int getValue() const;  // 声明加了 const
};

int Foo::getValue() {      // 定义忘记加 const
    return 0;
}
// 结果：编译器认为这是两个不同的函数，声明了但没有定义，链接时报错
```

## 六、完整示例：账本类

```cpp
#pragma once
#include <string>
#include <vector>

struct Record {
    std::string description;
    double amount;
};

class Ledger {
    std::vector<Record> records;
    mutable double cachedTotal = 0.0;  // 缓存
    mutable bool   cacheValid  = false;

public:
    // 修改对象状态：普通函数
    Ledger& addRecord(const std::string& desc, double amount) {
        records.push_back({desc, amount});
        cacheValid = false;   // 数据变了，缓存失效
        return *this;         // 支持链式调用
    }

    // 只读操作：const 函数
    double total() const {
        if (!cacheValid) {
            cachedTotal = 0.0;
            for (const auto& r : records)
                cachedTotal += r.amount;
            cacheValid = true;
        }
        return cachedTotal;
    }

    int count() const {
        return static_cast<int>(records.size());
    }

    void print() const {
        for (const auto& r : records)
            std::cout << r.description << ": " << r.amount << "\n";
        std::cout << "合计：" << total() << "\n";
    }
};
```

```cpp
#include "Ledger.h"

void showSummary(const Ledger& ledger) {  // const 引用，只能调用 const 函数
    std::cout << "共 " << ledger.count() << " 条记录，合计 " << ledger.total() << "\n";
    ledger.print();
}

int main() {
    Ledger l;
    l.addRecord("餐饮", 120.5)
     .addRecord("交通", 45.0)
     .addRecord("购书", 89.9);

    showSummary(l);   // 以 const 引用传入，合法
    return 0;
}
```

**输出：**

```
共 3 条记录，合计 255.4
餐饮: 120.5
交通: 45
购书: 89.9
合计：255.4
```

## 七、本课小结

| 概念 | 要点 |
|---|---|
| `this` 的本质 | 编译器隐式传入的当前对象指针，类型为 `T* const` |
| 解决同名冲突 | `this->member` 明确指定成员变量，与同名参数区分 |
| 链式调用 | 返回 `*this` 的引用，让调用可以连续在同一对象上进行 |
| `const` 成员函数 | 在括号后加 `const`，承诺不修改成员变量；声明和定义处都要加 |
| `const` 对象的限制 | `const` 对象只能调用 `const` 成员函数 |
| `const`/非`const` 重载 | 同名函数可以有两个版本，由对象的 const 性质决定调用哪个 |
| `mutable` | 允许特定成员在 `const` 函数里被修改，主要用于缓存；谨慎使用 |
| 指针成员的陷阱 | `const` 函数防止修改指针本身，但不防止修改指针所指向的内容 |

### 作业一：为已有类补全 const 标注（侦错练习）

下面是一个 `Rectangle` 类，**其中 `const` 的标注是不完整甚至错误的**。你的任务是：

1. 找出所有应该加 `const` 但没加的函数，补上
2. 找出不能加 `const` 的函数，确保它们没有被误标
3. 在 `main` 中写一个接收 `const Rectangle&` 参数的函数 `describe()`，验证你的标注是否正确（只有正确标注了 `const` 的函数，才能在 `describe()` 里被调用）

```cpp
class Rectangle {
public:
    double width;
    double height;

    void setSize(double w, double h) {
        width = w;
        height = h;
    }

    double area() {            // 应该是 const 吗？
        return width * height;
    }

    double perimeter() {       // 应该是 const 吗？
        return 2 * (width + height);
    }

    bool isSquare() {          // 应该是 const 吗？
        return width == height;
    }

    void scale(double factor) {
        width  *= factor;
        height *= factor;
    }

    void print() {             // 应该是 const 吗？
        std::cout << width << " x " << height << std::endl;
    }
};
```

### 作业二：链式调用构建器——QueryBuilder

设计一个模拟 SQL 查询构建过程的 `QueryBuilder` 类，要求：

- 成员变量：
  - `std::string tableName`
  - `std::string condition`（WHERE 条件，默认为空）
  - `int limitCount`（LIMIT 数量，默认为 -1 表示无限制）
  - `std::string orderField`（ORDER BY 字段，默认为空）

- 实现以下成员函数，**全部返回 `QueryBuilder&` 以支持链式调用**：
  - `from(std::string table)`：设置表名

  ```
  SELECT * FROM users WHERE age > 18 ORDER BY name LIMIT 10
  ```

  未设置的部分不出现在输出中。

- 在 `main` 中用链式调用的方式构建至少两条不同的查询，打印出来

**验证重点**：`build()` 必须是 `const` 函数；链式调用的每一步都要能在同一行写完。

### 作业三：带缓存的统计类——DataSet

设计一个存储一组整数并提供统计功能的 `DataSet` 类，要求：

- 成员变量：
  - `std::vector<int> data`：存放数据
  - 若干 `mutable` 缓存变量和缓存有效标志（由你自行设计）

- 实现以下函数：
  - `void add(int value)`：向数据集添加一个值（调用后所有缓存失效）
  - `void remove(int index)`：删除指定下标的值（调用后所有缓存失效）
  - `double mean() const`：返回平均值，**要求使用缓存**——第一次调用时计算并缓存，后续调用直接返回缓存值，直到数据变化为止
  - `int max() const`：返回最大值，同样要求缓存
  - `int min() const`：返回最小值，同样要求缓存
  - `void print() const`：打印所有数据和三个统计值

- 在 `main` 里验证缓存行为：
  - 添加几个数，调用 `mean()` 两次，打印一条消息确认第二次没有重新计算（比如在计算路径里加一行 `"缓存命中"` / `"重新计算"` 的输出来区分）
  - 再 `add()` 一个新值，调用 `mean()`，确认缓存正确失效并重新计算

**思考**：如果 `DataSet` 是空的（没有任何数据），`mean()`、`max()`、`min()` 应该怎么处理？选择一种合理的方案并在代码中实现。
