## 一、为什么需要运算符重载

先看一个没有运算符重载时的场景：

```cpp
class Vector2D {
public:
    double x, y;
};

Vector2D a = {1.0, 2.0};
Vector2D b = {3.0, 4.0};

// 不能用 + 直接相加，只能写成这样：
Vector2D c;
c.x = a.x + b.x;
c.y = a.y + b.y;
```

运算符重载之后：

```cpp
Vector2D c = a + b;  // 直觉上就是这样，为什么不让它工作？
```

**运算符重载的目的不是炫技，而是让自定义类型用起来像内置类型一样自然。** 数学向量就该能相加，复数就该能相乘，字符串就该能用 `+` 拼接。

---

## 二、运算符重载的本质

运算符重载的本质是：**为运算符定义一个函数，函数名固定为 `operator` 加上运算符符号。**

```cpp
// a + b  在编译器眼里，等价于以下两种之一：
a.operator+(b)      // 成员函数形式
operator+(a, b)     // 全局函数形式（通常写成友元）
```

这意味着：

- 运算符重载**就是写函数**，所有函数的规则都适用
- 参数类型、返回类型、`const`、引用——全部自己控制
- 编译器根据操作数的类型决定调用哪个版本

---

## 三、两种重载方式

### 3.1 成员函数重载

运算符函数写在类内部，左操作数隐式为 `this`。

```cpp
class Vector2D {
public:
    double x, y;

    // 左操作数是 this（调用者），右操作数是参数
    Vector2D operator+(const Vector2D& other) const {
        Vector2D result;
        result.x = x + other.x;
        result.y = y + other.y;
        return result;
    }
};

Vector2D a = {1, 2}, b = {3, 4};
Vector2D c = a + b;  // 编译器转换为 a.operator+(b)
```

### 3.2 友元函数重载

运算符函数写在类外部（全局），但声明为 `friend` 使其能访问私有成员。两个操作数都作为参数显式传入。

```cpp
class Vector2D {
public:
    double x, y;

    // 声明友元（让外部函数能访问私有成员）
    friend Vector2D operator+(const Vector2D& a, const Vector2D& b);
};

// 定义在类外
Vector2D operator+(const Vector2D& a, const Vector2D& b) {
    return {a.x + b.x, a.y + b.y};
}
```

### 3.3 该选哪种？

| 情况 | 推荐方式 |
|---|---|
| 左操作数是本类对象（`a + b`、`a == b`） | 成员函数或友元均可，成员函数更常见 |
| 左操作数不是本类（`std::cout << obj`、`2 * v`） | **必须用友元/全局函数**，因为左操作数不是你的类 |
| `=`、`[]`、`()`、`->` | **必须是成员函数**，语言规定 |
| `+=`、`-=` 等复合赋值 | 成员函数（因为需要修改左操作数） |
| `<<`、`>>` 流运算符 | **必须用友元**（左操作数是 `ostream`/`istream`，不是你的类） |

## 四、常用运算符逐一讲解

以下用一个完整的 `Vector2D` 类作为贯穿示例，逐步添加各类运算符。

```cpp
// Vector2D.h
#pragma once
#include <iostream>

class Vector2D {
public:
    double x = 0.0;
    double y = 0.0;

    Vector2D() = default;
    Vector2D(double x, double y) : x(x), y(y) {}
    
    // 以下各节逐步添加
};
```

---

### 4.1 算术运算符（`+` `-` `*`）

**关键点：返回新对象，不修改操作数，标记为 `const`。**

```cpp
// 成员函数写法
Vector2D operator+(const Vector2D& other) const {
    return {x + other.x, y + other.y};
}

Vector2D operator-(const Vector2D& other) const {
    return {x - other.x, y - other.y};
}

// 与标量相乘（成员函数，右操作数是标量）
Vector2D operator*(double scalar) const {
    return {x * scalar, y * scalar};
}
```

如果需要 `2.0 * v`（标量在左边），必须用友元：

```cpp
// 友元，声明在类内
friend Vector2D operator*(double scalar, const Vector2D& v);

// 定义在类外
Vector2D operator*(double scalar, const Vector2D& v) {
    return {v.x * scalar, v.y * scalar};
}
```

---

### 4.2 复合赋值运算符（`+=` `-=`）

**关键点：修改自身，返回 `*this` 的引用以支持链式调用。**

```cpp
Vector2D& operator+=(const Vector2D& other) {
    x += other.x;
    y += other.y;
    return *this;  // 返回自身引用
}

Vector2D& operator-=(const Vector2D& other) {
    x -= other.x;
    y -= other.y;
    return *this;
}
```

有了 `+=` 之后，`+` 可以复用它来实现，避免重复代码：

```cpp
// 用 += 实现 +，这是一种常见的惯用法
Vector2D operator+(const Vector2D& other) const {
    Vector2D result = *this;  // 拷贝自身
    result += other;           // 复用 +=
    return result;
}
```

---

### 4.3 比较运算符（`==` `!=` `<`）

**关键点：返回 `bool`，两个操作数都不修改，都加 `const`。**

```cpp
bool operator==(const Vector2D& other) const {
    return x == other.x && y == other.y;
}

bool operator!=(const Vector2D& other) const {
    return !(*this == other);  // 复用 ==，保持逻辑一致
}
```

> ⚠️ 浮点数比较 `==` 在实际工程中几乎不可靠（精度问题），上面写法仅作语法示范。实际项目里比较浮点应用误差范围：`std::abs(x - other.x) < 1e-9`。

```cpp
// 如果想让 Vector2D 能放进 std::set 或作为 std::map 的键，需要 <
bool operator<(const Vector2D& other) const {
    if (x != other.x) return x < other.x;
    return y < other.y;
}
```

---

### 4.4 流运算符（`<<` `>>`）⭐ 重点难点

这是最常用、也最容易写错的运算符。`std::cout << v` 中左操作数是 `std::ostream`，不是你的类，**只能用友元/全局函数**。

```cpp
// 在类内声明为友元
friend std::ostream& operator<<(std::ostream& os, const Vector2D& v);
friend std::istream& operator>>(std::istream& is, Vector2D& v);
```

```cpp
// 在类外定义
std::ostream& operator<<(std::ostream& os, const Vector2D& v) {
    os << "(" << v.x << ", " << v.y << ")";
    return os;  // 返回 os 的引用，支持链式：cout << a << b
}

std::istream& operator>>(std::istream& is, Vector2D& v) {
    is >> v.x >> v.y;  // v 不加 const，因为要修改它
    return is;
}
```

使用：

```cpp
Vector2D v = {3.0, 4.0};
std::cout << "向量是：" << v << std::endl;  // 输出：向量是：(3, 4)
std::cout << v << " 和 " << v * 2;         // 链式调用正常工作

std::cin >> v;  // 从键盘输入两个数给 v.x 和 v.y
```

**为什么返回 `ostream&` 而不是 `void`？**

因为 `std::cout << a << b` 实际上是 `(std::cout << a) << b`。如果返回 `void`，第一次调用后得到 `void`，无法再接 `<< b`。返回 `ostream&` 让这个表达式始终返回 `cout` 本身，才能继续链式调用。

---

### 4.5 赋值运算符（`=`）⭐ 重点难点

赋值运算符必须是成员函数，且有一个固定的写法套路：

```cpp
Vector2D& operator=(const Vector2D& other) {
    if (this == &other) return *this;  // 自赋值保护：a = a 不能出错
    x = other.x;
    y = other.y;
    return *this;  // 支持链式：a = b = c
}
```

**三步套路：**
1. 自赋值检查：`if (this == &other) return *this;`
2. 复制数据
3. `return *this;`

> 📌 对于 `Vector2D` 这类只含基本类型成员的类，编译器自动生成的赋值运算符已经足够用。你不需要手动写。需要手动写赋值运算符的场景是：类里有**指针**或**需要手动管理的资源**（L05 拷贝构造已经讲过这个场景）。

---

### 4.6 下标运算符（`[]`）

适用于希望像数组一样访问内部元素的类。必须是成员函数。

通常需要写两个版本：一个普通版（可读写），一个 `const` 版（只读）。

```cpp
class IntArray {
    int data[10] = {};
public:
    // 普通版：可读可写
    int& operator[](int index) {
        return data[index];
    }

    // const 版：const 对象调用，只读
    const int& operator[](int index) const {
        return data[index];
    }
};

IntArray arr;
arr[0] = 42;      // 调用普通版，返回引用，可赋值
int x = arr[0];   // 也是普通版

const IntArray& ref = arr;
int y = ref[0];   // 调用 const 版
// ref[0] = 1;    // 编译错误：const 版返回 const int&，不可赋值
```

---

### 4.7 前置与后置自增（`++`）⭐ 易混淆点

`++v`（前置）和 `v++`（后置）行为不同，写法也不同：

```cpp
// 前置 ++：先加，返回加之后的自身引用
Vector2D& operator++() {
    x += 1.0;
    y += 1.0;
    return *this;
}

// 后置 ++：先保存旧值，再加，返回旧值（值拷贝，不是引用）
// 参数列表里有个 int 占位符，这是 C++ 区分前置/后置的约定语法
Vector2D operator++(int) {
    Vector2D old = *this;  // 保存旧值
    x += 1.0;
    y += 1.0;
    return old;  // 返回旧值
}
```

```cpp
Vector2D v = {1, 2};

Vector2D a = ++v;  // v 先变成 (2,3)，a = (2,3)
Vector2D b = v++;  // b 拿到 (2,3)，然后 v 变成 (3,4)
```

**关键区别总结：**

| | 前置 `++v` | 后置 `v++` |
|---|---|---|
| 语义 | 先加，返回新值 | 先返回旧值，再加 |
| 返回类型 | `T&`（引用） | `T`（值拷贝） |
| 参数 | 无额外参数 | 有一个哑元 `int` |
| 性能 | 更高（无拷贝） | 有一次额外拷贝 |

> ⚡ 在循环中，对自定义类型优先用前置 `++i`，避免不必要的拷贝。对 `int` 无所谓（编译器会优化），但养成习惯有好处。

---

### 4.8 一元负号（`-v`）

一元运算符只有一个操作数，用成员函数时无需额外参数：

```cpp
Vector2D operator-() const {
    return {-x, -y};
}

Vector2D v = {3, 4};
Vector2D neg = -v;  // neg = (-3, -4)
```

## 五、不能重载的运算符

以下运算符**无法重载**，记住就好，不需要深究原因：

| 运算符 | 说明 |
|---|---|
| `::` | 作用域解析符 |
| `.` | 成员访问符 |
| `.*` | 成员指针访问符 |
| `?:` | 三目运算符 |
| `sizeof` | 大小运算符 |
| `typeid` | 类型识别 |
| `static_cast` 等 | 类型转换运算符（可以重载 `operator T()`，但那是另一个话题） |

## 六、注意事项

### ⚠️ 不要改变运算符的基本语义

重载后的运算符应当让使用者感到"符合直觉"。

```cpp
// 合理：Vector 相加就是各分量相加
Vector2D operator+(const Vector2D& other) const { ... }

// 糟糕：用 + 做减法，严重误导使用者
Vector2D operator+(const Vector2D& other) const {
    return {x - other.x, y - other.y};  // 反直觉，绝对不要这样写
}
```

如果你的类里 `+` 没有明显的自然含义，**不要重载它**。

---

### ⚠️ 算术运算符返回值，复合赋值返回引用

这是最常见的返回值错误：

```cpp
// ✅ 正确：+ 返回新对象（值）
Vector2D operator+(const Vector2D& other) const {
    return {x + other.x, y + other.y};
}

// ❌ 错误：不要返回局部变量的引用！
Vector2D& operator+(const Vector2D& other) const {
    Vector2D result = {x + other.x, y + other.y};
    return result;  // result 是局部变量，函数结束后销毁，引用变成悬空引用
}

// ✅ 正确：+= 返回 *this 的引用
Vector2D& operator+=(const Vector2D& other) {
    x += other.x;
    y += other.y;
    return *this;  // *this 的生命周期和对象相同，安全
}
```

---

### ⚠️ 赋值运算符必须检查自赋值

```cpp
// 忘了自赋值检查，在有动态内存时会崩溃
MyString& operator=(const MyString& other) {
    delete[] data;          // 先释放旧内存
    // 如果 other 就是 *this，这一步已经把 other.data 也删了！
    data = new char[other.len + 1];
    // 现在从已删除的内存里复制，未定义行为
    strcpy(data, other.data);
    return *this;
}
```

标准写法：

```cpp
MyString& operator=(const MyString& other) {
    if (this == &other) return *this;  // 第一行永远先检查
    delete[] data;
    data = new char[other.len + 1];
    strcpy(data, other.data);
    len = other.len;
    return *this;
}
```

---

### ⚠️ `<<` 的参数顺序不能反

```cpp
// ✅ 正确
std::ostream& operator<<(std::ostream& os, const Vector2D& v)

// ❌ 错误：参数顺序反了，cout << v 无法匹配
std::ostream& operator<<(const Vector2D& v, std::ostream& os)
```

---

### ⚠️ 对称运算符（`==`、`+`）应保持一致性

如果重载了 `==`，就应该同时重载 `!=`，并用 `==` 来实现 `!=`：

```cpp
bool operator!=(const Vector2D& other) const {
    return !(*this == other);  // 复用 ==，两者保证逻辑一致
}
```

如果两个独立实现，可能出现 `a == b` 为 `true` 但 `a != b` 也为 `true` 的逻辑矛盾。

## 七、完整示例：Complex 复数类

把本课知识点都用上，写一个完整的复数类：

```cpp
// Complex.h
#pragma once
#include <iostream>

class Complex {
public:
    double real = 0.0;
    double imag = 0.0;

    Complex() = default;
    Complex(double r, double i) : real(r), imag(i) {}

    // 算术
    Complex  operator+ (const Complex& o) const { return {real + o.real, imag + o.imag}; }
    Complex  operator- (const Complex& o) const { return {real - o.real, imag - o.imag}; }
    Complex  operator* (const Complex& o) const {
        return {real * o.real - imag * o.imag,
                real * o.imag + imag * o.real};
    }
    Complex  operator- ()                 const { return {-real, -imag}; }  // 一元负号

    // 复合赋值
    Complex& operator+=(const Complex& o) { real += o.real; imag += o.imag; return *this; }
    Complex& operator-=(const Complex& o) { real -= o.real; imag -= o.imag; return *this; }

    // 赋值
    Complex& operator=(const Complex& o) {
        if (this == &o) return *this;
        real = o.real;
        imag = o.imag;
        return *this;
    }

    // 比较
    bool operator==(const Complex& o) const { return real == o.real && imag == o.imag; }
    bool operator!=(const Complex& o) const { return !(*this == o); }

    // 流输出（友元）
    friend std::ostream& operator<<(std::ostream& os, const Complex& c);
    friend std::istream& operator>>(std::istream& is, Complex& c);
};

std::ostream& operator<<(std::ostream& os, const Complex& c) {
    os << c.real;
    if (c.imag >= 0) os << "+";
    os << c.imag << "i";
    return os;
}

std::istream& operator>>(std::istream& is, Complex& c) {
    is >> c.real >> c.imag;
    return is;
}
```

```cpp
// main.cpp
#include "Complex.h"

int main() {
    Complex a(3, 4), b(1, -2);

    std::cout << "a = " << a << std::endl;      // a = 3+4i
    std::cout << "b = " << b << std::endl;      // b = 1-2i
    std::cout << "a+b = " << a + b << std::endl;  // a+b = 4+2i
    std::cout << "a*b = " << a * b << std::endl;  // a*b = 11-2i

    a += b;
    std::cout << "a 之后 += b：" << a << std::endl;

    std::cout << (a == b ? "相等" : "不等") << std::endl;
    return 0;
}
```

## 八、本课小结

| 要点 | 结论 |
|---|---|
| 本质 | 运算符重载就是函数，名字是 `operator符号` |
| 两种方式 | 成员函数（左操作数是 `this`）vs 友元（两个操作数都显式传参） |
| `<<` / `>>` | 必须用友元，左操作数是 `ostream`/`istream` |
| `=` / `[]` / `()` / `->` | 必须是成员函数 |
| 算术返回值 | 返回新对象（值），不要返回局部变量的引用 |
| 复合赋值返回值 | 返回 `*this` 引用，支持链式 |
| 赋值运算符 | 三步套路：自赋值检查 → 复制 → `return *this` |
| 前置/后置 `++` | 前置返回引用、后置有哑元 `int` 参数并返回旧值 |
| 流运算符链式 | 返回 `ostream&` 才能 `cout << a << b` |

### 作业一：二维坐标点（基础热身）

定义一个 `Point` 类，成员变量为 `double x, y`，完成以下运算符重载：

### 作业二：有理数类（核心练习）

有理数是形如 $p/q$（$q \neq 0$）的分数。定义一个 `Rational` 类，成员变量为 `int numerator`（分子）和 `int denominator`（分母）。

要求实现以下运算符：

- `+`、`-`、`*`、`/`（分数的四则运算，结果需要化简到最简分数）
- `+=`、`-=`，要求复用 `+`、`-` 实现
- `==`、`!=`、`<`、`>`（注意：`2/4` 和 `1/2` 应当相等）
- `<<`：格式为 `分子/分母`，若分母为 1 则只打印分子（如 `3` 而不是 `3/1`）
- 前置和后置 `++`（分子加 1，分母不变）

**化简提示**：可用辗转相除法求最大公约数（GCD），然后分子分母同除以 GCD。

**需要注意的边界**：
- 分母不能为 0，构造时检查，若为 0 打印错误信息并将分母设为 1
- 分母始终保持为正数（负号统一在分子上）

这是本课体量最大的作业，`Rational` 类是运算符重载的经典练习对象，几乎涵盖本课所有知识点。

### 作业三：可打印的动态整数数组（综合挑战）

定义一个 `IntVec` 类，内部用 `int arr[100]` 存储数据，另有 `int size` 记录当前元素个数。

要求实现以下运算符：

- `[]`（下标运算符）：返回对应位置元素的引用，需要同时实现普通版和 `const` 版
- `<<`：打印格式为 `[1, 2, 3, 4]`，空数组打印 `[]`
- `==`：两个 `IntVec` 元素个数相同且对应位置元素全部相等时返回 `true`
- `+=`（追加单个元素）：`v += 5` 将整数 5 追加到末尾，若已满则打印提示不操作
- `+`（拼接两个 IntVec）：`v1 + v2` 返回一个新的 `IntVec`，内容为 v1 所有元素后跟 v2 所有元素，总长度超出 100 时截断

1. 通过 `[]` 修改元素后，用 `<<` 打印确认
2. 对 `const IntVec` 对象用 `[]` 读取元素
3. 用 `+=` 逐个追加若干元素，再用 `+` 拼接两个数组，打印结果
