## 一、什么是拷贝构造函数

**拷贝构造函数**是一种特殊的构造函数，专门用于"用一个已有对象来初始化一个新对象"。

它的固定签名是：

```cpp
ClassName(const ClassName& other);
```

参数必须是**同类型的常量引用**。为什么是引用而不是值？如果是值传递，传值本身又会触发一次拷贝构造，造成无限递归调用，直接栈溢出。

### 触发时机

拷贝构造函数在以下三种情况下被自动调用：

**① 用已有对象初始化新对象**

```cpp
Dog d1;
d1.name = "Max";

Dog d2 = d1;     // 触发拷贝构造
Dog d3(d1);      // 同上，另一种写法
```

**② 对象以值传递给函数**

```cpp
void foo(Dog d) { ... }  // d 是 dog 的一个副本

Dog dog;
foo(dog);   // 传参时触发拷贝构造
```

**③ 函数以值返回对象**

```cpp
Dog createDog() {
    Dog d;
    d.name = "Luna";
    return d;   // 返回时可能触发拷贝构造（现代编译器常会优化掉，即 RVO）
}
```

> 注意：赋值运算符 `=` 和拷贝构造是不同的。`Dog d2 = d1;` 是初始化，调用拷贝构造；`Dog d2; d2 = d1;` 是赋值，调用拷贝赋值运算符（`operator=`）。两者不要混淆。

## 二、默认拷贝构造函数：浅拷贝

如果你没有自定义拷贝构造函数，编译器会自动生成一个。它做的事情是：**逐成员复制（memberwise copy）**，也叫**浅拷贝（shallow copy）**。

对于只有普通数据成员（`int`、`double`、`std::string` 等）的类，浅拷贝完全够用：

```cpp
class Point {
public:
    double x = 0.0;
    double y = 0.0;
};

Point p1;
p1.x = 3.0; p1.y = 4.0;

Point p2 = p1;  // 编译器生成的浅拷贝：p2.x = p1.x; p2.y = p1.y;
p2.x = 10.0;   // 修改 p2 不影响 p1，完全安全
```

**问题出在类中含有指针成员时。**

浅拷贝只复制指针的值（地址），而不是指针指向的内容。结果是：两个对象的指针成员指向同一块堆内存。

```
p1.data ──────┐
              ▼
           [ 堆内存：某块数据 ]
              ▲
p2.data ──────┘
```

这会引发两个致命问题：

1. **修改其中一个对象，另一个对象的数据也被改变**（共享了同一块内存）
2. **两个对象析构时，都会尝试 `delete` 同一块内存——双重释放（double free），程序崩溃**

## 三、浅拷贝的崩溃示例

下面用一个管理动态数组的类来演示这个问题：

```cpp
#include <iostream>
#include <cstring>

class Buffer {
public:
    char* data;
    int   size;

    Buffer(int n) {
        size = n;
        data = new char[n];    // 在堆上分配内存
        memset(data, 0, n);
        std::cout << "构造：分配 " << n << " 字节，地址=" << (void*)data << std::endl;
    }

    ~Buffer() {
        std::cout << "析构：释放地址=" << (void*)data << std::endl;
        delete[] data;         // 释放堆内存
    }
};

int main() {
    Buffer b1(10);
    b1.data[0] = 'A';

    Buffer b2 = b1;            // 编译器默认浅拷贝：b2.data = b1.data（复制地址！）

    std::cout << "b1.data[0] = " << b1.data[0] << std::endl;  // A
    std::cout << "b2.data[0] = " << b2.data[0] << std::endl;  // A

    b2.data[0] = 'Z';          // 修改 b2

    std::cout << "修改 b2 后，b1.data[0] = " << b1.data[0] << std::endl;  // 也变成 Z！

    return 0;
    // b2 析构：delete[] data（释放那块内存）
    // b1 析构：delete[] data（再次释放同一块内存）→ 崩溃！double free
}
```

**输出（大概如下，崩溃前）：**

```
构造：分配 10 字节，地址=0x55a1b2c3d4e0
b1.data[0] = A
b2.data[0] = A
修改 b2 后，b1.data[0] = Z       ← 数据被意外篡改
析构：释放地址=0x55a1b2c3d4e0
析构：释放地址=0x55a1b2c3d4e0    ← 同一地址被释放两次 → 崩溃
```

这就是浅拷贝的核心问题。

## 四、深拷贝：正确的做法

**深拷贝（deep copy）**不只复制指针的值，而是重新分配一块新内存，然后把原来内存中的内容复制过去。两个对象各自拥有独立的堆内存。

```
b1.data ──→ [ 堆内存 A：内容"A..." ]

b2.data ──→ [ 堆内存 B：内容"A..." ]   ← 新分配，内容相同但地址不同
```

实现方式：自定义拷贝构造函数。

```cpp
class Buffer {
public:
    char* data;
    int   size;

    // 普通构造函数
    Buffer(int n) {
        size = n;
        data = new char[n];
        memset(data, 0, n);
    }

    // 自定义拷贝构造函数——深拷贝
    Buffer(const Buffer& other) {
        size = other.size;
        data = new char[size];          // ① 重新分配一块新内存
        memcpy(data, other.data, size); // ② 把原来的内容复制过来
        std::cout << "深拷贝：新地址=" << (void*)data << std::endl;
    }

    ~Buffer() {
        delete[] data;
    }
};
```

现在再运行之前的 `main`：

```
构造：分配 10 字节，地址=0x55a1b2c3d4e0
深拷贝：新地址=0x55a1b2c3f520      ← 新地址，独立内存
修改 b2 后，b1.data[0] = A         ← b1 不受影响
析构：释放地址=0x55a1b2c3f520
析构：释放地址=0x55a1b2c3d4e0      ← 释放各自的内存，安全
```

## 五、深拷贝的完整规范实现

深拷贝不只涉及拷贝构造函数。如果一个类需要深拷贝，通常也需要同时实现：

1. **拷贝构造函数** `T(const T& other)`
2. **拷贝赋值运算符** `T& operator=(const T& other)`
3. **析构函数** `~T()`

这就是 L08 会专门讲到的**三法则（Rule of Three）**。本课重点在拷贝构造函数，但先看一下拷贝赋值和它的区别：

```cpp
Buffer b1(10);
Buffer b2(10);

Buffer b3 = b1;   // ← 初始化，调用【拷贝构造函数】，b3 是新对象
b2 = b1;          // ← 赋值，调用【拷贝赋值运算符 operator=】，b2 已经存在
```

拷贝赋值的实现比拷贝构造更复杂，因为 `b2` 本身已经持有一块旧内存，需要先释放再分配：

```cpp
Buffer& Buffer::operator=(const Buffer& other) {
    if (this == &other) return *this;   // ① 自赋值检查（b2 = b2 的情况）

    delete[] data;                      // ② 释放自己原来的内存

    size = other.size;
    data = new char[size];              // ③ 重新分配
    memcpy(data, other.data, size);     // ④ 复制内容

    return *this;                       // ⑤ 返回自身引用，支持链式赋值
}
```

> 本课重点掌握拷贝构造函数。拷贝赋值运算符在 L07（运算符重载）和 L08（Rule of Three）中会更深入讲解。

## 六、什么时候需要自定义拷贝构造函数

**判断原则很简单：**

> 如果类的析构函数需要手动 `delete` 或释放任何资源，那么这个类几乎一定需要自定义拷贝构造函数。

反过来说，如果类里只有 `int`、`double`、`std::string`、`std::vector` 这类成员（它们自己管理自己的内存），编译器默认的浅拷贝是安全的，不需要自己写。

| 成员类型 | 是否需要自定义拷贝构造 |
|---|---|
| `int`、`double`、`bool` 等基本类型 | 不需要 |
| `std::string`、`std::vector` 等标准库类型 | 不需要（它们已经实现了深拷贝） |
| 裸指针 `T*`（指向堆内存） | **需要** |
| 文件句柄、网络连接、互斥锁等资源 | **需要**（通常是禁止拷贝，见下） |

### 禁止拷贝

有些类在语义上就不应该被拷贝（比如管理独占资源的类）。C++11 起可以显式删除拷贝构造函数：

```cpp
class FileHandle {
public:
    FileHandle(const FileHandle&) = delete;             // 禁止拷贝构造
    FileHandle& operator=(const FileHandle&) = delete;  // 禁止拷贝赋值

    // ...
};

FileHandle f1("log.txt");
FileHandle f2 = f1;  // 编译错误，明确告诉调用者：这个类不能拷贝
```

这比让程序在运行时崩溃要好得多。

## 七、注意事项

### ⚠️ 参数必须是引用，不能是值

```cpp
// 错误：值传递会无限递归调用自身
Dog(Dog other);         // ❌

// 正确：必须是引用
Dog(const Dog& other);  // ✅
```

### ⚠️ 拷贝构造 ≠ 赋值运算符

```cpp
Dog d2 = d1;    // 这是初始化，调用拷贝构造函数
d2 = d1;        // 这是赋值，调用 operator=

// 两者是完全不同的函数，自定义其中一个不会自动覆盖另一个
```

### ⚠️ 浅拷贝的 bug 常常不会立刻崩溃

浅拷贝的 double free 问题，往往在析构时才爆发，表现为程序结束时崩溃，或者出现随机内存错误。用 valgrind 或 AddressSanitizer 可以很快定位这类问题：

```bash
# 编译时加上 Address Sanitizer
g++ -fsanitize=address -g main.cpp -o main
./main
```

输出会精确指出哪里发生了 double free。

### ⚠️ 深拷贝忘记处理 size/length 等元数据

只复制数据内容，忘了复制描述数据的元信息，是深拷贝最常见的漏洞：

```cpp
// 错误：只复制了 data，忘记复制 size
Buffer(const Buffer& other) {
    data = new char[other.size];
    memcpy(data, other.data, other.size);
    // 忘了：size = other.size;  ← 导致 size 是垃圾值
}
```

### ⚠️ `std::string` 和 `std::vector` 已经处理好了深拷贝

不要重复造轮子。如果你的类成员都是标准库类型，编译器自动生成的逐成员拷贝会正确地调用它们各自的拷贝构造函数，产生深拷贝效果：

```cpp
class Person {
public:
    std::string name;   // std::string 自己实现了深拷贝
    int age;
};

Person p1;
p1.name = "Alice";
Person p2 = p1;         // 完全安全，不需要自定义拷贝构造函数
p2.name = "Bob";        // p1.name 不受影响
```

## 八、完整示例：动态字符串类

综合本课内容，实现一个简化版的字符串类 `MyString`，管理自己的堆内存：

```cpp
#include <iostream>
#include <cstring>

class MyString {
public:
    char* str;
    int   len;

    // 构造函数
    MyString(const char* s = "") {
        len = strlen(s);
        str = new char[len + 1];
        strcpy(str, s);
    }

    // 深拷贝构造函数
    MyString(const MyString& other) {
        len = other.len;
        str = new char[len + 1];
        strcpy(str, other.str);
        std::cout << "[深拷贝] \"" << str << "\" 已复制到新地址" << std::endl;
    }

    // 析构函数
    ~MyString() {
        delete[] str;
    }

    void print() const {
        std::cout << "\"" << str << "\" (len=" << len << ")" << std::endl;
    }
};

// 值传递——触发拷贝构造
void printString(MyString s) {
    s.print();
}

int main() {
    MyString s1("Hello");
    MyString s2 = s1;        // 拷贝构造：初始化

    s2.str[0] = 'J';         // 修改 s2

    std::cout << "s1: "; s1.print();   // 应该仍然是 "Hello"
    std::cout << "s2: "; s2.print();   // 应该是 "Jello"

    std::cout << "\n值传递测试：" << std::endl;
    printString(s1);         // 触发拷贝构造，传入副本

    return 0;
}
```

**输出：**

```
[深拷贝] "Hello" 已复制到新地址
s1: "Hello" (len=5)
s2: "Jello" (len=5)

值传递测试：
[深拷贝] "Hello" 已复制到新地址
"Hello" (len=5)
```

## 九、本课小结

| 概念 | 要点 |
|---|---|
| 拷贝构造函数签名 | `T(const T& other)`，参数必须是引用 |
| 触发时机 | 用对象初始化、值传参、值返回（共三种） |
| 浅拷贝 | 编译器默认行为，逐成员复制；含裸指针时引发共享内存和 double free |
| 深拷贝 | 重新 `new` 内存并复制内容；每个对象独立持有自己的资源 |
| 何时自定义 | 析构函数需要手动释放资源时，必须自定义拷贝构造 |
| 禁止拷贝 | `= delete` 明确禁用，比运行时崩溃更安全 |
| 标准库类型 | `std::string` / `std::vector` 等已实现深拷贝，无需手动处理 |
