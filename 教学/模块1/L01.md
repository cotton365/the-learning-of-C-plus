## 一、什么是类，什么是对象

在 C 语言里，数据和操作数据的函数是分离的。你会有一个 `struct Student` 存数据，然后有一堆独立函数 `printStudent()`、`setScore()` 去操作它。它们之间没有任何强制绑定关系，任何人都可以随意修改数据。

C++ 的类（`class`）把**数据**和**操作数据的函数**绑在了一起，形成一个独立的单元。

```
类（class）= 数据（成员变量） + 行为（成员函数）
```

**类是模板，对象是实例。**

类就像一张建筑图纸，对象就是按照图纸盖出来的房子。图纸本身不是房子，但每一栋按图纸盖出来的房子，都拥有图纸里描述的结构。

```cpp
// 类：图纸
class Dog {
public:
    std::string name;
    int age;

    void bark() {
        std::cout << name << " says: Woof!" << std::endl;
    }
};

// 对象：按图纸造出来的实例
Dog d1;          // 创建一个 Dog 对象
d1.name = "Max";
d1.age = 3;
d1.bark();       // 输出：Max says: Woof!

Dog d2;          // 再创建一个，和 d1 互不干扰
d2.name = "Luna";
```

## 二、class 与 struct 的区别

C++ 保留了 `struct`，并赋予它和 `class` 几乎相同的能力——两者都可以有成员变量、成员函数、继承。

**唯一的语法区别：默认访问权限不同。**

| | `class` | `struct` |
|---|---|---|
| 默认成员访问权限 | `private` | `public` |
| 默认继承方式 | `private` 继承 | `public` 继承 |

```cpp
class Foo {
    int x;  // 默认 private，外部无法访问
};

struct Bar {
    int x;  // 默认 public，外部可以直接访问
};
```

**惯例上的约定（非语法规定）：**

- 用 `struct` 表示纯数据聚合，比如坐标点 `Point`、颜色 `Color`——通常不含复杂逻辑
- 用 `class` 表示有行为、有封装意图的类型

这只是编程惯例，编译器不会强制你这样做。

## 三、成员变量与成员函数

### 3.1 成员变量

成员变量是属于对象的数据，每个对象都有自己独立的一份。

```cpp
class Circle {
public:
    double radius;   // 成员变量：每个 Circle 对象都有自己的 radius
    std::string color;
};

Circle c1, c2;
c1.radius = 5.0;
c2.radius = 10.0;   // c1 和 c2 的 radius 互不影响
```

### 3.2 成员函数

成员函数是定义在类内部（或与类关联）的函数，它可以直接访问该类的成员变量，无需传参。

```cpp
class Circle {
public:
    double radius;

    double area() {
        return 3.14159 * radius * radius;  // 直接访问 radius，不用传参
    }

    double circumference() {
        return 2 * 3.14159 * radius;
    }
};

Circle c;
c.radius = 7.0;
std::cout << c.area() << std::endl;  // 输出：153.938...
```

### 3.3 成员函数在类外定义

当类的内容较多时，通常把成员函数的**声明**放在类内，**定义**写在类外（或另一个 `.cpp` 文件）。语法使用 `类名::函数名`：

```cpp
class Rectangle {
public:
    double width;
    double height;

    double area();          // 声明在类内
    double perimeter();
};

// 定义在类外，用 :: 说明它属于哪个类
double Rectangle::area() {
    return width * height;
}

double Rectangle::perimeter() {
    return 2 * (width + height);
}
```

## 四、声明与定义的分离（.h / .cpp）

真实项目中，一个类通常被拆成两个文件：

**`Rectangle.h`（头文件）**——只放声明

```cpp
#pragma once
#include <string>

class Rectangle {
public:
    double width;
    double height;

    double area();
    double perimeter();
    void print();
};
```

**`Rectangle.cpp`（源文件）**——放函数定义

```cpp
#include "Rectangle.h"
#include <iostream>

double Rectangle::area() {
    return width * height;
}

double Rectangle::perimeter() {
    return 2 * (width + height);
}

void Rectangle::print() {
    std::cout << "Rectangle " << width << " x " << height << std::endl;
}
```

**`main.cpp`**——使用这个类

```cpp
#include "Rectangle.h"

int main() {
    Rectangle r;
    r.width  = 4.0;
    r.height = 6.0;
    r.print();
    std::cout << "Area: " << r.area() << std::endl;
    return 0;
}
```

这种分离的好处：
- 其他文件只需要 `#include "Rectangle.h"` 就能用这个类，不需要知道实现细节
- 修改实现（`.cpp`）时，只需重新编译这一个文件，不影响其他模块

## 五、对象的创建方式

### 5.1 栈上创建（最常见）

```cpp
Circle c;           // 调用默认构造（后续课程讲）
c.radius = 3.0;
```

对象随函数调用结束自动销毁，无需手动管理内存。

### 5.2 堆上创建（new / delete）

```cpp
Circle* p = new Circle();   // 在堆上分配，返回指针
p->radius = 5.0;            // 通过指针访问成员用 ->
std::cout << p->area();

delete p;   // 必须手动释放！否则内存泄漏
p = nullptr;
```

> ⚠️ 现代 C++ 中，**几乎不需要裸 `new`**。后续模块五会讲智能指针，它可以自动管理堆内存。现在只需要知道 `->` 的用法即可。

### 5.3 `.` 与 `->` 的区别

```cpp
Circle c;      // 栈对象
c.area();      // 用 .

Circle* p = &c;  // 指向对象的指针
p->area();     // 用 ->，等价于 (*p).area()
```

## 六、注意事项

### ⚠️ 成员变量未初始化

类的成员变量**不会自动初始化为 0**（在没有构造函数的情况下）。

```cpp
class Foo {
public:
    int x;
    double y;
};

Foo f;
std::cout << f.x;  // 未定义行为！值不确定，可能是任何数
```

养成好习惯：声明时给成员变量一个默认值（C++11 起支持）：

```cpp
class Foo {
public:
    int x = 0;
    double y = 0.0;
};
```

更规范的做法是在构造函数里初始化（L03 会详细讲）。

### ⚠️ class 默认是 private，别忘了写 public

```cpp
class Dog {
    std::string name;   // 忘写 public，外部无法访问
};

Dog d;
d.name = "Max";  // 编译错误：'name' is private
```

### ⚠️ 头文件中用 `#pragma once` 防止重复包含

同一个头文件被多个 `.cpp` 包含时，如果没有保护，类会被重复定义导致编译错误。

```cpp
#pragma once   // 现代编译器都支持，推荐用这个

// 或者用传统的 include guard：
#ifndef RECTANGLE_H
#define RECTANGLE_H
// ...类的声明...
#endif
```

### ⚠️ 不要在 `.h` 文件里定义函数（内联函数除外）

如果函数定义写在头文件里，被多个 `.cpp` 包含后会产生**重复定义错误**（链接阶段报错）。成员函数的定义应当放在 `.cpp` 文件中。

> 例外：在类内直接定义的函数会被编译器隐式视为 `inline`，不会出现重复定义问题。但仍建议保持声明与定义分离的习惯。

## 七、完整示例：银行账户

综合运用本课所学，写一个简单的银行账户类：

**`BankAccount.h`**

```cpp
#pragma once
#include <string>

class BankAccount {
public:
    std::string owner;
    double balance = 0.0;

    void deposit(double amount);
    void withdraw(double amount);
    void printStatement();
};
```

**`BankAccount.cpp`**

```cpp
#include "BankAccount.h"
#include <iostream>

void BankAccount::deposit(double amount) {
    if (amount <= 0) {
        std::cout << "存款金额必须大于 0" << std::endl;
        return;
    }
    balance += amount;
    std::cout << "存入 " << amount << "，当前余额：" << balance << std::endl;
}

void BankAccount::withdraw(double amount) {
    if (amount > balance) {
        std::cout << "余额不足" << std::endl;
        return;
    }
    balance -= amount;
    std::cout << "取出 " << amount << "，当前余额：" << balance << std::endl;
}

void BankAccount::printStatement() {
    std::cout << "账户持有人：" << owner
              << "，余额：" << balance << std::endl;
}
```

**`main.cpp`**

```cpp
#include "BankAccount.h"

int main() {
    BankAccount acc;
    acc.owner   = "Alice";
    acc.balance = 1000.0;

    acc.deposit(500.0);
    acc.withdraw(200.0);
    acc.withdraw(2000.0);  // 余额不足
    acc.printStatement();

    return 0;
}
```

**输出：**

```
存入 500，当前余额：1500
取出 200，当前余额：1300
余额不足
账户持有人：Alice，余额：1300
```

## 八、本课小结

| 概念 | 要点 |
|---|---|
| 类 vs 对象 | 类是模板，对象是实例，每个对象有独立的成员变量 |
| `class` vs `struct` | 唯一区别：默认访问权限，`class` 是 `private`，`struct` 是 `public` |
| 成员函数 | 可直接访问成员变量，无需传参；用 `类名::` 在类外定义 |
| 文件分离 | 声明放 `.h`，定义放 `.cpp`，用 `#pragma once` 防重复包含 |
| 对象访问 | 栈对象用 `.`，指针用 `->` |
| 初始化 | 成员变量不自动为 0，声明时给默认值或在构造函数中初始化 |
