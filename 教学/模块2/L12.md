## 一、为什么需要虚函数

### 1.1 问题场景:基类指针调用派生类方法

假设你在开发一个图形渲染系统:

```cpp
class Shape {
public:
    void draw() {
        std::cout << "绘制一个形状" << std::endl;
    }
};

class Circle : public Shape {
public:
    void draw() {
        std::cout << "绘制一个圆形" << std::endl;
    }
};

class Rectangle : public Shape {
public:
    void draw() {
        std::cout << "绘制一个矩形" << std::endl;
    }
};
```

现在你想用统一的方式处理不同的形状:

```cpp
int main() {
    Circle c;
    Rectangle r;
    
    Shape* shapes[2];
    shapes[0] = &c;
    shapes[1] = &r;
    
    for (int i = 0; i < 2; i++) {
        shapes[i]->draw();  // 期望:调用各自的 draw()
    }
}
```

**输出:**
```
绘制一个形状
绘制一个形状
```

**问题所在:**虽然 `shapes[0]` 实际指向 `Circle` 对象,`shapes[1]` 指向 `Rectangle` 对象,但调用的都是 `Shape::draw()`!

这是因为 C++ 默认使用**静态绑定**(编译期绑定):编译器看到 `Shape*` 类型的指针,就直接调用 `Shape::draw()`,不管它实际指向什么对象。

### 1.2 虚函数的解决方案

在基类的函数前加 `virtual` 关键字,启用**动态绑定**(运行时绑定):

```cpp
class Shape {
public:
    virtual void draw() {  // ← 关键:加 virtual
        std::cout << "绘制一个形状" << std::endl;
    }
};

class Circle : public Shape {
public:
    void draw() override {  // override 是可选的,但建议加上
        std::cout << "绘制一个圆形" << std::endl;
    }
};

class Rectangle : public Shape {
public:
    void draw() override {
        std::cout << "绘制一个矩形" << std::endl;
    }
};
```

现在再运行上面的代码:

**输出:**
```
绘制一个圆形
绘制一个矩形
```

完美!虚函数实现了**运行时多态**:通过基类指针/引用调用函数时,根据对象的**实际类型**决定调用哪个版本。

## 二、虚函数的基本语法

### 2.1 声明虚函数

在基类中用 `virtual` 声明:

```cpp
class Base {
public:
    virtual void func() { /* 基类实现 */ }
    virtual int getValue() const { return 0; }
    virtual ~Base() {}  // 虚析构函数(L14 详讲)
};
```

### 2.2 覆盖(Override)虚函数

派生类中重新定义同名同参数的函数:

```cpp
class Derived : public Base {
public:
    void func() override { /* 派生类实现 */ }
    int getValue() const override { return 42; }
};
```

**`override` 关键字**(C++11):
- 可选,但强烈推荐使用
- 编译器会检查是否真的覆盖了基类虚函数
- 如果没有对应的虚函数,编译器报错,防止拼写错误

**错误示例:**
```cpp
class Derived : public Base {
public:
    void func() const override {  // ❌ 编译错误!
        // Base::func() 不是 const,参数不匹配,无法覆盖
    }
};
```

### 2.3 虚函数覆盖的要求

要正确覆盖虚函数,必须满足:
1. 函数名相同
2. 参数列表相同(类型、顺序、个数)
3. const 属性相同
4. 返回类型相同(或协变,见下)

**协变返回类型:**派生类可以返回基类返回类型的派生类指针/引用:

```cpp
class Base {
public:
    virtual Base* clone() { return new Base(*this); }
};

class Derived : public Base {
public:
    Derived* clone() override {  // ✅ 协变:返回 Derived*
        return new Derived(*this);
    }
};
```

## 三、虚函数表(vtable)原理

这是本课最核心也最需要深入理解的内容。

### 3.1 什么是 vtable

虚函数表(Virtual Table, vtable)是编译器为每个**含有虚函数的类**生成的一张函数指针表。

```cpp
class Animal {
public:
    virtual void speak() { std::cout << "..." << std::endl; }
    virtual void move() { std::cout << "移动" << std::endl; }
    void eat() { std::cout << "进食" << std::endl; }  // 非虚函数
};
```

编译器会为 `Animal` 类生成一个 vtable:

```
Animal 的 vtable:
┌──────────────────────┐
│ &Animal::speak       │
│ &Animal::move        │
└──────────────────────┘
```

注意:`eat()` 不是虚函数,所以不在 vtable 中。

### 3.2 虚函数指针(vptr)

每个**含有虚函数的类的对象**,在内存布局的**最开始位置**会有一个隐藏的指针,叫做虚函数指针(vptr),指向该类的 vtable。

```
Animal 对象内存布局:
┌────────────────────┐
│ vptr ─────────────┼──→ Animal 的 vtable
├────────────────────┤
│ 其他成员变量       │
└────────────────────┘
```

### 3.3 派生类的 vtable

当派生类覆盖了虚函数时,它会有自己的 vtable:

```cpp
class Dog : public Animal {
public:
    void speak() override { std::cout << "汪汪!" << std::endl; }
    // move() 没有覆盖,继承基类版本
};
```

```
Dog 的 vtable:
┌──────────────────────┐
│ &Dog::speak          │  ← 覆盖了,指向 Dog 的版本
│ &Animal::move        │  ← 没覆盖,继承 Animal 的版本
└──────────────────────┘
```

```
Dog 对象内存布局:
┌────────────────────┐
│ vptr ─────────────┼──→ Dog 的 vtable
├────────────────────┤
│ Animal 的成员      │
├────────────────────┤
│ Dog 自己的成员     │
└────────────────────┘
```

### 3.4 虚函数调用过程

当通过基类指针/引用调用虚函数时:

```cpp
Animal* p = new Dog();
p->speak();  // 动态绑定
```

**调用步骤:**
1. 解引用指针 `p`,找到对象
2. 读取对象开头的 `vptr`,找到 vtable
3. 在 vtable 中查找 `speak()` 对应的函数指针(假设是第 0 项)
4. 调用 `vtable[0]` 指向的函数,即 `Dog::speak()`

**伪代码表示:**
```cpp
// p->speak() 实际执行:
(*p->vptr[0])(p);  // vptr[0] 是 &Dog::speak
```

这就是**运行时多态**的实现原理:函数调用在运行时根据对象的实际类型决定。

### 3.5 完整示例验证

```cpp
#include <iostream>

class Animal {
public:
    virtual void speak() { std::cout << "Animal speak" << std::endl; }
    virtual void move() { std::cout << "Animal move" << std::endl; }
    
    void printVptrAddress() {
        // 打印对象的 vptr 地址(位于对象开头)
        void** vptr = *(void***)this;
        std::cout << "vptr: " << vptr << std::endl;
    }
};

class Dog : public Animal {
public:
    void speak() override { std::cout << "Dog speak" << std::endl; }
};

class Cat : public Animal {
public:
    void speak() override { std::cout << "Cat speak" << std::endl; }
    void move() override { std::cout << "Cat move" << std::endl; }
};

int main() {
    Animal a;
    Dog d;
    Cat c;
    
    std::cout << "=== vptr 地址 ===" << std::endl;
    a.printVptrAddress();  // Animal 的 vptr
    d.printVptrAddress();  // Dog 的 vptr(不同!)
    c.printVptrAddress();  // Cat 的 vptr(也不同!)
    
    std::cout << "\n=== 多态调用 ===" << std::endl;
    Animal* animals[3] = {&a, &d, &c};
    for (int i = 0; i < 3; i++) {
        animals[i]->speak();  // 根据实际类型调用
        animals[i]->move();
        std::cout << std::endl;
    }
}
```

**可能的输出:**
```
=== vptr 地址 ===
vptr: 0x555555557d20
vptr: 0x555555557d40
vptr: 0x555555557d60

=== 多态调用 ===
Animal speak
Animal move

Dog speak
Animal move

Cat speak
Cat move
```

注意三个对象的 vptr 指向不同的 vtable,这是多态的基础。

## 四、静态绑定 vs 动态绑定

### 4.1 什么时候使用动态绑定

**动态绑定的三个必要条件:**
1. 函数是虚函数
2. 通过**基类指针或引用**调用
3. 指针/引用指向的是派生类对象

```cpp
Dog d;

// ① 动态绑定
Animal* p = &d;
p->speak();  // ✅ 调用 Dog::speak()

// ② 动态绑定
Animal& r = d;
r.speak();   // ✅ 调用 Dog::speak()
```

### 4.2 静态绑定的情况

**不满足上述条件时,使用静态绑定:**

```cpp
Dog d;

// ③ 静态绑定:直接用对象调用
d.speak();   // ✅ 调用 Dog::speak(),但是编译期确定

// ④ 静态绑定:非虚函数
Animal* p = &d;
p->eat();    // ✅ eat() 不是虚函数,调用 Animal::eat()

// ⑤ 静态绑定:用对象而非指针/引用
Animal a = d;  // 对象切片(slicing)!
a.speak();     // ✅ 调用 Animal::speak(),d 的 Dog 部分被切掉了
```

**⚠️ 对象切片陷阱:**

```cpp
void processAnimal(Animal a) {  // ❌ 按值传递
    a.speak();  // 永远调用 Animal::speak()
}

void processAnimal(Animal& a) {  // ✅ 按引用传递
    a.speak();  // 多态调用,根据实际类型
}

Dog d;
processAnimal(d);
```

按值传递时,`Dog` 对象被切片成 `Animal` 对象,丢失了派生类特有的部分和 vptr。

## 五、虚函数的性能开销

虚函数不是零成本的,理解其开销有助于你在性能敏感场景做出权衡。

### 5.1 内存开销

- **vptr:** 每个对象多 8 字节(64 位系统)的虚函数指针
- **vtable:** 每个类多一张函数指针表(所有对象共享)

```cpp
class Empty { };               // sizeof: 1 字节(空类优化)
class WithVirtual {
    virtual void f() {}
};                             // sizeof: 8 字节(vptr)

class WithData {
    int x;
};                             // sizeof: 4 字节
class WithDataAndVirtual {
    int x;
    virtual void f() {}
};                             // sizeof: 16 字节(4 字节对齐 + vptr 8 字节)
```

### 5.2 时间开销

- **虚函数调用:**多两次间接访问(读 vptr + 查 vtable),比普通函数调用慢约 25%
- **编译器优化受限:**虚函数无法内联(inline),因为调用目标在运行时才确定

**非关键路径可以放心使用,关键路径需权衡:**
- GUI 事件处理、插件系统:虚函数开销可忽略 ✅
- 游戏引擎内循环、数值计算:考虑避免虚函数 ⚠️

## 六、注意事项

### ⚠️ 构造函数不能是虚函数

构造函数的作用是创建对象,在对象创建完成前,vptr 还没设置好,无法实现多态。

```cpp
class Base {
public:
    virtual Base() {}  // ❌ 编译错误
};
```

### ⚠️ 构造/析构函数中调用虚函数的陷阱

在构造函数中调用虚函数,**不会触发多态**:

```cpp
class Base {
public:
    Base() {
        init();  // 调用的是 Base::init()
    }
    virtual void init() {
        std::cout << "Base init" << std::endl;
    }
};

class Derived : public Base {
public:
    void init() override {
        std::cout << "Derived init" << std::endl;
    }
};

Derived d;  // 输出: "Base init"
```

原因:构造 `Derived` 对象时,先构造 `Base` 部分。此时 `Derived` 部分还没构造,vptr 还指向 `Base` 的 vtable,所以调用的是 `Base::init()`。

**同理,析构函数中调用虚函数也不会触发多态。**

### ⚠️ 虚函数与默认参数

虚函数的默认参数值采用**静态绑定**:

```cpp
class Base {
public:
    virtual void show(int x = 10) {
        std::cout << "Base: " << x << std::endl;
    }
};

class Derived : public Base {
public:
    void show(int x = 20) override {
        std::cout << "Derived: " << x << std::endl;
    }
};

Base* p = new Derived();
p->show();  // 输出: "Derived: 10"(函数是 Derived,参数是 Base 的默认值!)
```

**建议:**虚函数的默认参数值在基类和派生类中保持一致,或干脆不用默认参数。

### ⚠️ 虚函数与 final 关键字

`final` 关键字(C++11)防止虚函数被进一步覆盖:

```cpp
class Base {
public:
    virtual void func() {}
};

class Derived : public Base {
public:
    void func() override final {}  // 不允许再覆盖
};

class MoreDerived : public Derived {
public:
    void func() override {}  // ❌ 编译错误
};
```

也可以用 `final` 防止类被继承:

```cpp
class FinalClass final {  // 不允许被继承
};

class Derived : public FinalClass {};  // ❌ 编译错误
```

### ⚠️ 虚继承的 virtual vs 虚函数的 virtual

这是两个完全独立的概念,都用 `virtual` 关键字但含义不同:

| 概念 | 位置 | 作用 |
|---|---|---|
| 虚继承 | 继承列表 | 解决菱形继承的数据副本问题 |
| 虚函数 | 函数声明 | 实现运行时多态 |

```cpp
class Base {
public:
    virtual void func() {}  // 虚函数
};

class Derived : public virtual Base {  // 虚继承
    // ...
};
```

不要混淆!

## 七、完整综合示例:图形渲染系统

```cpp
#include <iostream>
#include <vector>
#include <memory>
#include <cmath>

// ──────────────────────────────────
// 基类:抽象形状
// ──────────────────────────────────
class Shape {
protected:
    std::string color;
    
public:
    Shape(std::string c) : color(c) {}
    
    virtual ~Shape() {}  // 虚析构函数(重要!)
    
    // 纯虚函数(L13 详讲),强制派生类实现
    virtual void draw() const = 0;
    virtual double area() const = 0;
    
    // 虚函数,提供默认实现
    virtual void showInfo() const {
        std::cout << "颜色: " << color 
                  << ", 面积: " << area() << std::endl;
    }
    
    std::string getColor() const { return color; }
};

// ──────────────────────────────────
// 派生类:圆形
// ──────────────────────────────────
class Circle : public Shape {
private:
    double radius;
    
public:
    Circle(std::string c, double r) : Shape(c), radius(r) {}
    
    void draw() const override {
        std::cout << "[圆形] 半径 " << radius << std::endl;
    }
    
    double area() const override {
        return 3.14159 * radius * radius;
    }
};

// ──────────────────────────────────
// 派生类:矩形
// ──────────────────────────────────
class Rectangle : public Shape {
private:
    double width, height;
    
public:
    Rectangle(std::string c, double w, double h) 
        : Shape(c), width(w), height(h) {}
    
    void draw() const override {
        std::cout << "[矩形] " << width << " × " << height << std::endl;
    }
    
    double area() const override {
        return width * height;
    }
    
    // 覆盖 showInfo,添加额外信息
    void showInfo() const override {
        std::cout << "矩形 - ";
        Shape::showInfo();  // 调用基类版本
        std::cout << "  周长: " << 2 * (width + height) << std::endl;
    }
};

// ──────────────────────────────────
// 派生类:三角形
// ──────────────────────────────────
class Triangle : public Shape {
private:
    double a, b, c;  // 三边长
    
public:
    Triangle(std::string color, double a, double b, double c)
        : Shape(color), a(a), b(b), c(c) {}
    
    void draw() const override {
        std::cout << "[三角形] 边长 " << a << ", " << b << ", " << c << std::endl;
    }
    
    double area() const override {
        // 海伦公式
        double s = (a + b + c) / 2;
        return std::sqrt(s * (s-a) * (s-b) * (s-c));
    }
};

// ──────────────────────────────────
// 使用多态
// ──────────────────────────────────
int main() {
    // 使用智能指针管理内存(L34 详讲)
    std::vector<std::shared_ptr<Shape>> shapes;
    
    shapes.push_back(std::make_shared<Circle>("红色", 5.0));
    shapes.push_back(std::make_shared<Rectangle>("蓝色", 4.0, 6.0));
    shapes.push_back(std::make_shared<Triangle>("绿色", 3.0, 4.0, 5.0));
    
    std::cout << "=== 绘制所有形状 ===" << std::endl;
    for (const auto& shape : shapes) {
        shape->draw();  // 多态调用
    }
    
    std::cout << "\n=== 显示详细信息 ===" << std::endl;
    for (const auto& shape : shapes) {
        shape->showInfo();  // 多态调用
        std::cout << std::endl;
    }
    
    std::cout << "=== 统计总面积 ===" << std::endl;
    double totalArea = 0;
    for (const auto& shape : shapes) {
        totalArea += shape->area();  // 多态调用
    }
    std::cout << "总面积: " << totalArea << std::endl;
}
```

**输出:**
```
=== 绘制所有形状 ===
[圆形] 半径 5
[矩形] 4 × 6
[三角形] 边长 3, 4, 5

=== 显示详细信息 ===
颜色: 红色, 面积: 78.5397

矩形 - 颜色: 蓝色, 面积: 24
  周长: 20

颜色: 绿色, 面积: 6

=== 统计总面积 ===
总面积: 108.54
```

## 八、本课小结

| 概念 | 核心要点 |
|---|---|
| 虚函数定义 | 基类用 `virtual` 声明,派生类用 `override` 覆盖 |
| 运行时多态 | 通过基类指针/引用调用虚函数,根据对象实际类型决定调用哪个版本 |
| vtable | 编译器为每个含虚函数的类生成的函数指针表 |
| vptr | 对象内存开头的指针,指向该类的 vtable |
| 动态绑定条件 | ① 虚函数 ② 基类指针/引用 ③ 指向派生类对象 |
| 静态绑定 | 直接用对象调用、非虚函数、对象切片时发生 |
| 性能开销 | 每对象多 vptr(8 字节),调用多 2 次间接访问,无法内联 |
| 构造函数陷阱 | 构造/析构中调用虚函数不会触发多态 |
| 默认参数陷阱 | 虚函数的默认参数值采用静态绑定 |

**核心口诀:**
- 虚函数实现运行时多态
- vptr 指向 vtable,vtable 存函数指针
- 基类指针/引用才能触发动态绑定

### 作业一:虚函数基础与多态调用(考查虚函数语法 + 动态绑定机制)

设计一个简单的员工管理系统:

```
      Employee(员工基类)
     /              \
FullTime           PartTime
(全职员工)         (兼职员工)
```

要求:
1. `Employee` 基类:包含 `std::string name` 和 `int id`,提供有参构造函数
   - 虚函数 `virtual double calculateSalary() const`:返回 0(基类默认实现)
   - 虚函数 `virtual void printInfo() const`:打印姓名和 ID
   
2. `FullTime` 派生类:新增 `double baseSalary` 和 `double bonus`
   - 覆盖 `calculateSalary()`:返回 `baseSalary + bonus`
   - 覆盖 `printInfo()`:调用基类版本后,打印薪资信息

### 作业二:vtable 原理探索与验证(考查 vtable/vptr 理解 + 静态/动态绑定)

这道题需要你**深入理解虚函数表的机制**,是本课的重点难点。

**第一步:构建类层次结构**

```cpp
class Base {
public:
    virtual void funcA() { std::cout << "Base::funcA" << std::endl; }
    virtual void funcB() { std::cout << "Base::funcB" << std::endl; }
    void funcC() { std::cout << "Base::funcC" << std::endl; }  // 非虚
};

class Derived1 : public Base {
public:
    void funcA() override { std::cout << "Derived1::funcA" << std::endl; }
    // funcB 不覆盖,继承基类版本
    void funcC() { std::cout << "Derived1::funcC" << std::endl; }
};

class Derived2 : public Base {
public:
    void funcA() override { std::cout << "Derived2::funcA" << std::endl; }
    void funcB() override { std::cout << "Derived2::funcB" << std::endl; }
};
```

**第二步:实验验证**

在 `main` 中完成以下实验,并记录输出:

1. **对象大小实验:**
   ```cpp
   std::cout << "sizeof(Base): " << sizeof(Base) << std::endl;
   std::cout << "sizeof(Derived1): " << sizeof(Derived1) << std::endl;
   ```
   思考:为什么 `Base` 的大小是 8 字节(64 位系统)?

2. **vptr 地址实验:**
   ```cpp
   Base b;
   Derived1 d1;
   Derived2 d2;
   
   void** vptr_b = *(void***)&b;
   void** vptr_d1 = *(void***)&d1;
   void** vptr_d2 = *(void***)&d2;
   
   std::cout << "Base vptr: " << vptr_b << std::endl;
   std::cout << "Derived1 vptr: " << vptr_d1 << std::endl;
   std::cout << "Derived2 vptr: " << vptr_d2 << std::endl;
   ```
   观察:三个 vptr 是否相同?为什么?

3. **动态绑定 vs 静态绑定实验:**
   ```cpp
   Derived1 d1;
   Base* p = &d1;
   Base& r = d1;
   
   // 测试以下调用,分别输出什么?
   d1.funcA();      // (1)
   d1.funcC();      // (2)
   p->funcA();      // (3)
   p->funcC();      // (4)
   r.funcA();       // (5)
   r.funcC();       // (6)
   ```

4. **对象切片实验:**
   ```cpp
   Derived1 d1;
   Base b = d1;  // 对象切片
   b.funcA();    // 输出什么?
   ```
