## 一、为什么需要继承

假设你在写一个游戏，有多种角色：

```cpp
class Warrior {
public:
    std::string name;
    int hp;
    int attack;

    void move()  { std::cout << name << " 移动" << std::endl; }
    void slash()  { /* 战士专属技能 */ }
};

class Mage {
public:
    std::string name;
    int hp;
    int mana;

    void move()  { std::cout << name << " 移动" << std::endl; }
    void cast_spell() { /* 法师专属技能 */ }
};

class Archer {
public:
    std::string name;
    int hp;
    int arrows;

    void move()  { std::cout << name << " 移动" << std::endl; }
    void shoot() { /* 弓手专属技能 */ }
};
```

`name`、`hp`、`move()` 在三个类里几乎一模一样——这是重复代码。每次修改 `move()` 的逻辑，要同时改三处，极易遗漏。

继承的核心价值：**把共同的部分提取到基类，让派生类只关注自己独有的东西。**

```
Character（基类）
├── name, hp, move()         ← 公共部分
│
├── Warrior（派生类）── attack, slash()
├── Mage（派生类）   ── mana, cast_spell()
└── Archer（派生类） ── arrows, shoot()
```

## 二、继承的基本语法

```cpp
class Derived : public Base {
    // 继承方式（最常用 public）
};
```

完整例子：

```cpp
class Character {
public:
    std::string name;
    int hp;

    Character(std::string n, int h) : name(n), hp(h) {}

    void move() {
        std::cout << name << " 移动" << std::endl;
    }

    void showStatus() {
        std::cout << name << " HP: " << hp << std::endl;
    }
};

class Warrior : public Character {
public:
    int attack;

    Warrior(std::string n, int h, int atk)
        : Character(n, h),   // 调用基类构造函数（下节详讲）
          attack(atk) {}

    void slash() {
        std::cout << name << " 使出斩击！伤害：" << attack << std::endl;
    }
};

int main() {
    Warrior w("Arthur", 200, 50);

    w.move();         // 继承自 Character
    w.showStatus();   // 继承自 Character
    w.slash();        // Warrior 自己的方法
    std::cout << w.name << std::endl;  // 继承的成员变量
}
```

**输出：**
```
Arthur 移动
Arthur HP: 200
Arthur 使出斩击！伤害：50
Arthur
```

## 三、三种继承方式：public / protected / private

这是本课最需要细致理解的核心，也是最容易混淆的地方。

继承方式决定的是：**基类的成员，在派生类中的可见性如何变化。**

首先明确基类三种访问权限的含义：

| 基类成员权限 | 谁能访问 |
|---|---|
| `public` | 任何人（类内、类外、派生类）|
| `protected` | 类内 + 派生类（类外不行）|
| `private` | 只有类自己（派生类也不行）|

### 3.1 三种继承方式的变化规则

继承方式就像一个"权限上限过滤器"——成员在派生类中的实际权限取最小值：

```
实际权限 = min(基类原始权限, 继承方式)
```

| 基类成员原始权限 | public 继承后 | protected 继承后 | private 继承后 |
|---|---|---|---|
| `public` | `public` | `protected` | `private` |
| `protected` | `protected` | `protected` | `private` |
| `private` | **不可访问** | **不可访问** | **不可访问** |

注意最后一行：**无论哪种继承方式，基类的 `private` 成员派生类都无法直接访问。** 私有成员在派生类对象的内存里确实存在，但派生类的代码不能直接碰它，只能通过基类提供的 `public`/`protected` 函数间接操作。

### 3.2 用代码验证

```cpp
class Base {
public:
    int pub = 1;
protected:
    int pro = 2;
private:
    int pri = 3;
};

// ── public 继承（最常用）──
class D_pub : public Base {
public:
    void test() {
        pub = 10;    // ✅ public，可访问
        pro = 20;    // ✅ protected，可访问
        // pri = 30; // ❌ private，不可访问
    }
};

D_pub d;
d.pub = 100;   // ✅ pub 仍是 public，类外可访问
// d.pro = 200; // ❌ pro 是 protected，类外不可访问

// ── protected 继承 ──
class D_pro : protected Base {
public:
    void test() {
        pub = 10;    // ✅ pub 降为 protected，类内可访问
        pro = 20;    // ✅ pro 仍是 protected
    }
};

D_pro dp;
// dp.pub = 100; // ❌ pub 已降为 protected，类外不可访问

// ── private 继承 ──
class D_pri : private Base {
public:
    void test() {
        pub = 10;    // ✅ pub 降为 private，类内可访问
        pro = 20;    // ✅ pro 降为 private，类内可访问
    }
};

D_pri dpr;
// dpr.pub = 100; // ❌ pub 已降为 private，类外不可访问
```

### 3.3 实际开发中用哪种

**绝大多数情况用 `public` 继承。**

`public` 继承表达的是"is-a"关系：Warrior **是一个** Character。这是继承最自然的语义。

`protected` 和 `private` 继承表达的是"用基类的实现来实现派生类"，语义上更接近**组合**，实际工程中极少使用。理解即可，不必深究。

## 四、派生类的构造函数

这是本课第二个需要细致理解的核心内容。

### 4.1 为什么必须显式调用基类构造函数

对象构造时，**基类的部分必须先被构造**，然后才是派生类自己的部分。道理很简单：派生类依赖基类提供的成员，如果基类没构造好，这些成员的值不确定。

调用基类构造函数的语法写在派生类构造函数的**初始化列表**中：

```cpp
class Animal {
public:
    std::string species;
    int age;

    Animal(std::string s, int a) : species(s), age(a) {
        std::cout << "Animal 构造：" << species << std::endl;
    }
};

class Dog : public Animal {
public:
    std::string breed;

    Dog(std::string breed, int age)
        : Animal("犬科", age),  // ← 先初始化基类部分
          breed(breed)          // ← 再初始化派生类自己的成员
    {
        std::cout << "Dog 构造：" << breed << std::endl;
    }
};

int main() {
    Dog d("拉布拉多", 3);
}
```

**输出：**
```
Animal 构造：犬科
Dog 构造：拉布拉多
```

基类构造函数**一定先执行**。

### 4.2 如果不显式调用基类构造函数

如果初始化列表里没有写基类构造函数，编译器会自动调用**基类的默认构造函数（无参）**。

**但如果基类没有默认构造函数，就会编译报错：**

```cpp
class Base {
public:
    Base(int x) {}   // 只有有参构造，没有无参构造
};

class Derived : public Base {
public:
    Derived() {}   // ❌ 编译错误：Base 没有默认构造函数
};

// 正确写法：
class Derived : public Base {
public:
    Derived(int x) : Base(x) {}   // ✅ 显式调用
};
```

这是初学者非常高频遇到的编译错误，原因就在这里。

### 4.3 构造与析构的顺序

```
构造顺序：基类构造函数 → 派生类成员初始化 → 派生类构造函数体
析构顺序：派生类析构函数 → 基类析构函数（严格相反）
```

```cpp
class Base {
public:
    Base()  { std::cout << "Base 构造" << std::endl; }
    ~Base() { std::cout << "Base 析构" << std::endl; }
};

class Derived : public Base {
public:
    Derived()  { std::cout << "Derived 构造" << std::endl; }
    ~Derived() { std::cout << "Derived 析构" << std::endl; }
};

int main() {
    Derived d;
}
```

**输出：**
```
Base 构造
Derived 构造
Derived 析构
Base 析构
```

析构顺序相反的原因：派生类析构时可能还依赖基类的资源，所以必须等派生类清理完毕，基类才能销毁自己。

## 五、protected 成员的实际意义

`protected` 在模块一没有特别强调，在继承中才真正体现价值：**它是专门为派生类设计的"半开放"接口。**

```cpp
class Shape {
protected:
    double x, y;   // 坐标：外部不该直接改，但派生类可以读写

public:
    Shape(double x, double y) : x(x), y(y) {}

    void moveTo(double nx, double ny) { x = nx; y = ny; }
};

class Circle : public Shape {
private:
    double radius;

public:
    Circle(double x, double y, double r)
        : Shape(x, y), radius(r) {}

    void describe() {
        // ✅ 派生类可以访问 protected 的 x, y
        std::cout << "圆心(" << x << ", " << y
                  << ") 半径 " << radius << std::endl;
    }
};

int main() {
    Circle c(0, 0, 5);
    c.describe();
    // c.x = 10;  ❌ 类外不能访问 protected
    c.moveTo(3, 4);
    c.describe();
}
```

**设计建议：**

- 如果成员只属于基类内部实现，用 `private`
- 如果成员需要在派生类中直接访问，用 `protected`
- 尽量少暴露 `protected` 成员变量，优先提供 `protected` 函数接口，降低耦合

## 六、继承 vs 组合

继承是"is-a"（是一个），组合是"has-a"（有一个）。

```
Dog is-a Animal       → 用继承：class Dog : public Animal
Car has-a Engine      → 用组合：class Car { Engine engine; }
```

**一个容易判断错误的例子：**

```cpp
// ❌ 错误的设计：Stack 继承 vector
class Stack : public std::vector<int> {
    // Stack 不是 vector，只是用 vector 来实现栈
    // 这会把 push_back、insert、erase 等方法全暴露出去
};

// ✅ 正确的设计：组合
class Stack {
private:
    std::vector<int> data;
public:
    void push(int x) { data.push_back(x); }
    void pop()       { data.pop_back(); }
    int  top()       { return data.back(); }
};
```

**判断方法：把"X is a Y"大声说出来，听起来奇怪就不该用继承。**

- "Warrior is a Character" → 通顺 → 用继承 ✅
- "Stack is a vector" → 奇怪 → 用组合 ✅
- "Car is an Engine" → 明显错误 → 用组合 ✅

## 七、注意事项

### ⚠️ 基类没有默认构造函数时，派生类必须显式调用

这是本课最高频的编译错误，见第四节的例子。

### ⚠️ 派生类不能直接访问基类的 private 成员

```cpp
class Base {
private:
    int secret = 42;
};

class Derived : public Base {
public:
    void foo() {
        std::cout << secret;  // ❌ 编译错误
    }
};
```

内存里确实有 `secret`，但代码层面不可访问。需要基类提供 `protected` 或 `public` 接口。

### ⚠️ 名称遮蔽（name hiding）

派生类中定义了与基类同名的函数，**基类的所有同名重载都会被遮蔽**：

```cpp
class Base {
public:
    void greet()          { std::cout << "Hello!" << std::endl; }
    void greet(int times) { /* 打印多次 */ }
};

class Derived : public Base {
public:
    void greet() {   // 遮蔽了 Base 的所有 greet 重载！
        std::cout << "Hi!" << std::endl;
    }
};

Derived d;
d.greet();      // ✅
d.greet(3);     // ❌ 编译错误：Base::greet(int) 被遮蔽

// 如果需要保留基类的重载，在 Derived 中加：
// using Base::greet;
```

### ⚠️ 析构函数不加 virtual 的隐患（现在先记住，L14 详讲）

```cpp
Base* p = new Derived();
delete p;   // ⚠️ Base 析构不是 virtual，只调用 Base 的析构
            //    Derived 的析构被跳过，可能资源泄漏
```

L14 会专门深讲。现在只需知道这个坑存在。

## 八、完整综合示例：员工管理系统

```cpp
// Employee.h
#pragma once
#include <iostream>
#include <string>

class Employee {
protected:
    std::string name;
    int id;
    double baseSalary;

public:
    Employee(std::string name, int id, double base)
        : name(name), id(id), baseSalary(base) {}

    void printBasicInfo() const {
        std::cout << "[" << id << "] " << name
                  << "  底薪：" << baseSalary << std::endl;
    }

    double getBaseSalary() const { return baseSalary; }
    std::string getName()  const { return name; }
};

class FullTimeEmployee : public Employee {
private:
    double bonus;

public:
    FullTimeEmployee(std::string name, int id, double base, double bonus)
        : Employee(name, id, base), bonus(bonus) {}

    double totalSalary() const { return baseSalary + bonus; }

    void printInfo() const {
        printBasicInfo();
        std::cout << "  奖金：" << bonus
                  << "  合计：" << totalSalary() << std::endl;
    }
};

class PartTimeEmployee : public Employee {
private:
    double hourlyRate;
    int hoursWorked;

public:
    PartTimeEmployee(std::string name, int id, double rate, int hours)
        : Employee(name, id, 0), hourlyRate(rate), hoursWorked(hours) {}

    double totalSalary() const { return hourlyRate * hoursWorked; }

    void printInfo() const {
        printBasicInfo();
        std::cout << "  时薪：" << hourlyRate
                  << "  工时：" << hoursWorked
                  << "  合计：" << totalSalary() << std::endl;
    }
};
```

```cpp
// main.cpp
#include "Employee.h"

int main() {
    FullTimeEmployee e1("Alice", 1001, 8000, 2000);
    PartTimeEmployee e2("Bob",   1002, 50, 80);

    e1.printInfo();
    std::cout << std::endl;
    e2.printInfo();

    std::cout << "\n" << e1.getName()
              << " 底薪：" << e1.getBaseSalary() << std::endl;
}
```

**输出：**
```
[1001] Alice  底薪：8000
  奖金：2000  合计：10000

[1002] Bob  底薪：0
  时薪：50  工时：80  合计：4000

Alice 底薪：8000
```

## 九、本课小结

| 概念 | 核心要点 |
|---|---|
| 继承语法 | `class Derived : public Base`，绝大多数用 `public` 继承 |
| is-a 关系 | 继承表达"派生类是一种基类"，不满足时用组合 |
| 三种继承方式 | `public` 保持原权限；`protected` 将 public 降为 protected；`private` 全降为 private；基类 `private` 始终不可访问 |
| 派生类构造 | 在初始化列表调用基类构造；不写则调用基类默认构造（若无则报错）|
| 构造/析构顺序 | 构造：基类 → 派生类；析构：派生类 → 基类，严格相反 |
| `protected` 成员 | 专为派生类设计的"半开放"接口，类外不可访问 |
| 名称遮蔽 | 同名函数遮蔽基类所有重载，用 `using Base::func` 恢复 |
