## 1. RTTI 基础概念

### 1.1 什么是 RTTI？

**RTTI（Run-Time Type Information，运行时类型信息）** 是 C++ 提供的一种机制，允许程序在运行时获取对象的实际类型信息。

```cpp
#include <iostream>
#include <typeinfo>

class Base {
public:
    virtual ~Base() {}  // 必须有虚函数，RTTI才能工作
};

class Derived : public Base {
public:
    void derivedMethod() {
        std::cout << "Derived method called
";
    }
};

int main() {
    Base* ptr = new Derived();
    
    // 使用 typeid 获取类型信息
    std::cout << "类型名称: " << typeid(*ptr).name() << std::endl;
    
    // 比较类型
    if (typeid(*ptr) == typeid(Derived)) {
        std::cout << "ptr 指向 Derived 对象
";
    }
    
    delete ptr;
    return 0;
}
```

### 1.2 RTTI 的两个主要工具

C++ 提供了两个主要的 RTTI 工具：

1. **`typeid` 运算符**：返回对象的类型信息（`std::type_info` 对象）
2. **`dynamic_cast` 运算符**：安全的类型转换，主要用于多态类型的向下转型

```cpp
#include <iostream>
#include <typeinfo>

class Animal {
public:
    virtual ~Animal() {}
    virtual void makeSound() = 0;
};

class Dog : public Animal {
public:
    void makeSound() override { std::cout << "Woof!
"; }
    void fetch() { std::cout << "Fetching...
"; }
};

class Cat : public Animal {
public:
    void makeSound() override { std::cout << "Meow!
"; }
    void climb() { std::cout << "Climbing...
"; }
};

void interact(Animal* animal) {
    // 使用 typeid 检查类型
    std::cout << "动物类型: " << typeid(*animal).name() << std::endl;
    
    // 使用 dynamic_cast 尝试转换
    if (Dog* dog = dynamic_cast<Dog*>(animal)) {
        dog->fetch();
    } else if (Cat* cat = dynamic_cast<Cat*>(animal)) {
        cat->climb();
    }
}

int main() {
    Animal* myDog = new Dog();
    Animal* myCat = new Cat();
    
    interact(myDog);  // 输出: 动物类型: 3Dog, Fetching...
    interact(myCat);  // 输出: 动物类型: 3Cat, Climbing...
    
    delete myDog;
    delete myCat;
    return 0;
}
```

### 1.3 RTTI 的前提条件

⚠️ **重要：RTTI 只对多态类型有效**

```cpp
class NonPolymorphic {
    int x;
};

class Polymorphic {
public:
    virtual ~Polymorphic() {}
};

int main() {
    NonPolymorphic* np = new NonPolymorphic();
    Polymorphic* p = new Polymorphic();
    
    // ❌ 不推荐：非多态类型的 typeid 只返回静态类型
    std::cout << typeid(*np).name() << std::endl;
    
    // ✅ 正确：多态类型的 typeid 返回实际类型
    std::cout << typeid(*p).name() << std::endl;
    
    delete np;
    delete p;
    return 0;
}
```

**RTTI 工作的必要条件：**
- 类必须至少有一个虚函数（通常是虚析构函数）
- 编译器必须启用 RTTI（大多数编译器默认启用）

## 2. dynamic_cast 详解

### 2.1 dynamic_cast 的基本语法

`dynamic_cast` 是一种类型转换运算符，专门用于处理多态类型的转换。

```cpp
dynamic_cast<目标类型>(源对象)
```

**四种使用形式：**

```cpp
class Base {
public:
    virtual ~Base() {}
};

class Derived : public Base {
public:
    void derivedFunc() {}
};

int main() {
    Derived* d = new Derived();
    Base* b = d;
    
    // 1. 指针形式：向下转型
    Derived* d2 = dynamic_cast<Derived*>(b);
    if (d2) {  // 转换成功
        d2->derivedFunc();
    }
    
    // 2. 引用形式（失败时抛出异常）
    try {
        Derived& dRef = dynamic_cast<Derived&>(*b);
        dRef.derivedFunc();
    } catch (std::bad_cast& e) {
        std::cout << "转换失败: " << e.what() << std::endl;
    }
    
    delete d;
    return 0;
}
```

### 2.2 向下转型（Downcasting）

向下转型是从基类指针/引用转换到派生类指针/引用。

```cpp
#include <iostream>

class Shape {
public:
    virtual ~Shape() {}
    virtual void draw() = 0;
};

class Circle : public Shape {
private:
    double radius;
public:
    Circle(double r) : radius(r) {}
    void draw() override {
        std::cout << "绘制圆形，半径: " << radius << std::endl;
    }
    double getRadius() const { return radius; }
};

class Rectangle : public Shape {
private:
    double width, height;
public:
    Rectangle(double w, double h) : width(w), height(h) {}
    void draw() override {
        std::cout << "绘制矩形，宽: " << width << "，高: " << height << std::endl;
    }
    double getArea() const { return width * height; }
};

void processShape(Shape* shape) {
    shape->draw();
    
    // 安全的向下转型
    if (Circle* circle = dynamic_cast<Circle*>(shape)) {
        std::cout << "这是圆形，半径: " << circle->getRadius() << std::endl;
    } else if (Rectangle* rect = dynamic_cast<Rectangle*>(shape)) {
        std::cout << "这是矩形，面积: " << rect->getArea() << std::endl;
    }
}

int main() {
    Shape* shapes[] = {
        new Circle(5.0),
        new Rectangle(4.0, 6.0)
    };
    
    for (Shape* shape : shapes) {
        processShape(shape);
        std::cout << "---
";
    }
    
    for (Shape* shape : shapes) {
        delete shape;
    }
    
    return 0;
}
```

### 2.3 侧向转型（Crosscasting）

在多重继承中，`dynamic_cast` 可以实现侧向转型。

```cpp
#include <iostream>

class Animal {
public:
    virtual ~Animal() {}
};

class Mammal : public Animal {
public:
    void nurse() { std::cout << "哺乳中...
"; }
};

class Bird : public Animal {
public:
    void fly() { std::cout << "飞行中...
"; }
};

class Bat : public Mammal, public Bird {
public:
    void echolocate() { std::cout << "回声定位中...
"; }
};

int main() {
    Bat* bat = new Bat();
    
    // 向上转型到 Mammal
    Mammal* mammal = bat;
    
    // 侧向转型：从 Mammal* 转换到 Bird*
    Bird* bird = dynamic_cast<Bird*>(mammal);
    if (bird) {
        std::cout << "侧向转型成功！
";
        bird->fly();
    }
    
    delete bat;
    return 0;
}
```

### 2.4 指针转换 vs 引用转换

```cpp
#include <iostream>

class Base {
public:
    virtual ~Base() {}
};

class Derived : public Base {
public:
    void show() { std::cout << "Derived
"; }
};

void testPointerCast(Base* base) {
    // 指针转换：失败返回 nullptr
    Derived* derived = dynamic_cast<Derived*>(base);
    if (derived) {
        std::cout << "指针转换成功
";
        derived->show();
    } else {
        std::cout << "指针转换失败
";
    }
}

void testReferenceCast(Base& base) {
    try {
        // 引用转换：失败抛出 std::bad_cast 异常
        Derived& derived = dynamic_cast<Derived&>(base);
        std::cout << "引用转换成功
";
        derived.show();
    } catch (std::bad_cast& e) {
        std::cout << "引用转换失败: " << e.what() << std::endl;
    }
}

int main() {
    Derived d;
    Base b;
    
    std::cout << "=== 测试指针转换 ===
";
    testPointerCast(&d);  // 成功
    testPointerCast(&b);  // 失败
    
    std::cout << "
=== 测试引用转换 ===
";
    testReferenceCast(d);  // 成功
    testReferenceCast(b);  // 抛出异常
    
    return 0;
}
```

## 3. typeid 运算符

### 3.1 typeid 的基本用法

`typeid` 运算符返回一个 `std::type_info` 对象，包含类型信息。

```cpp
#include <iostream>
#include <typeinfo>

class Base {
public:
    virtual ~Base() {}
};

class Derived : public Base {};

int main() {
    int i = 42;
    double d = 3.14;
    Base* b = new Derived();
    
    // 获取类型名称
    std::cout << "i 的类型: " << typeid(i).name() << std::endl;
    std::cout << "d 的类型: " << typeid(d).name() << std::endl;
    std::cout << "*b 的类型: " << typeid(*b).name() << std::endl;
    
    // 比较类型
    if (typeid(*b) == typeid(Derived)) {
        std::cout << "b 指向 Derived 对象
";
    }
    
    delete b;
    return 0;
}
```

### 3.2 typeid 在多态中的应用

```cpp
#include <iostream>
#include <typeinfo>
#include <vector>

class Employee {

"; }

"; }

"; }

    std::cout << "  工程师: " << engineerCount << " 人

";
```

### 3.3 type_info 类

`std::type_info` 是 `typeid` 返回的类型，定义在 `<typeinfo>` 头文件中。

```cpp
#include <iostream>
#include <typeinfo>

class MyClass {
public:
    virtual ~MyClass() {}
};

int main() {
    MyClass obj;
    const std::type_info& ti = typeid(obj);
    
    // type_info 的主要成员函数
    std::cout << "类型名称: " << ti.name() << std::endl;
    std::cout << "哈希码: " << ti.hash_code() << std::endl;
    
    // 比较类型
    if (ti == typeid(MyClass)) {
        std::cout << "类型匹配
";
    }
    
    // 前后关系（用于排序）
    const std::type_info& ti2 = typeid(int);
    if (ti.before(ti2)) {
        std::cout << "MyClass 在 int 之前
";
    }
    
    return 0;
}
```

## 4. RTTI 的使用场景和最佳实践

### 4.1 什么时候使用 RTTI？

✅ **适合使用 RTTI 的场景：**

```cpp
// 1. 处理异构容器
std::vector<Shape*> shapes;
for (Shape* shape : shapes) {
    if (Circle* circle = dynamic_cast<Circle*>(shape)) {
        // 只有圆形才有的操作
        circle->setRadius(10);
    }
}

// 2. 序列化/反序列化
void serialize(std::ostream& os, const Base* obj) {
    if (typeid(*obj) == typeid(DerivedA)) {
        os << "TypeA" << ...;
    } else if (typeid(*obj) == typeid(DerivedB)) {
        os << "TypeB" << ...;
    }
}

// 3. 调试和日志
void logObject(const Base* obj) {
    std::cout << "对象类型: " << typeid(*obj).name() << std::endl;
}
```

❌ **不应该使用 RTTI 的场景：**

```cpp
// ❌ 错误：用 RTTI 替代虚函数
void process(Animal* animal) {
    if (typeid(*animal) == typeid(Dog)) {
        // 狗的处理逻辑
    } else if (typeid(*animal) == typeid(Cat)) {
        // 猫的处理逻辑
    }
    // 应该使用虚函数！
}

// ✅ 正确：使用虚函数
class Animal {
public:
    virtual void process() = 0;
};
```

### 4.2 RTTI vs 虚函数

```cpp
#include <iostream>
#include <vector>
#include <typeinfo>

class GameObject {
public:
    virtual ~GameObject() {}
    
    // ✅ 推荐：使用虚函数实现多态行为
    virtual void update() = 0;
    virtual void render() = 0;
};

class Player : public GameObject {
private:
    int health;
public:
    Player() : health(100) {}
    
    void update() override {
        // 玩家更新逻辑
    }
    
    void render() override {
        std::cout << "渲染玩家，生命值: " << health << std::endl;
    }
    
    // 玩家特有的方法
    void takeDamage(int damage) {
        health -= damage;
    }
};

class Enemy : public GameObject {
private:
    int attackPower;
public:
    Enemy() : attackPower(20) {}
    
    void update() override {
        // 敌人更新逻辑
    }
    
    void render() override {
        std::cout << "渲染敌人，攻击力: " << attackPower << std::endl;
    }
    
    // 敌人特有的方法
    void attack(Player* player) {
        player->takeDamage(attackPower);
    }
};

// ❌ 不好的设计：过度使用 RTTI
void processGameObjectBad(GameObject* obj) {
    if (typeid(*obj) == typeid(Player)) {
        std::cout << "处理玩家
";
        // 玩家逻辑
    } else if (typeid(*obj) == typeid(Enemy)) {
        std::cout << "处理敌人
";
        // 敌人逻辑
    }
}

// ✅ 好的设计：使用虚函数
void processGameObjectGood(GameObject* obj) {
    obj->update();  // 多态调用
    obj->render();  // 多态调用
}

// ✅ 合理使用 RTTI：特定的类型检查
void checkCollision(GameObject* obj1, GameObject* obj2) {
    // 只有玩家和敌人碰撞才有意义
    Player* player = dynamic_cast<Player*>(obj1);
    Enemy* enemy = dynamic_cast<Enemy*>(obj2);
    
    if (player && enemy) {
        std::cout << "玩家与敌人发生碰撞！
";
        enemy->attack(player);
    }
}

int main() {
    std::vector<GameObject*> objects = {
        new Player(),
        new Enemy(),
        new Player()
    };
    
    // 使用虚函数处理所有对象
    for (GameObject* obj : objects) {
        processGameObjectGood(obj);
    }
    
    // 使用 RTTI 进行特定检查
    checkCollision(objects[0], objects[1]);
    
    for (GameObject* obj : objects) {
        delete obj;
    }
    
    return 0;
}
```

### 4.3 性能考虑

```cpp
#include <iostream>
#include <chrono>
#include <vector>

class Base {
public:
    virtual ~Base() {}
    virtual int getType() const { return 0; }
};

class Derived1 : public Base {
public:
    int getType() const override { return 1; }
};

class Derived2 : public Base {
public:
    int getType() const override { return 2; }
};

// 方法1：使用 RTTI
void processWithRTTI(Base* obj) {
    if (typeid(*obj) == typeid(Derived1)) {
        // 处理 Derived1
    } else if (typeid(*obj) == typeid(Derived2)) {
        // 处理 Derived2
    }
}

// 方法2：使用虚函数
void processWithVirtual(Base* obj) {
    int type = obj->getType();
    if (type == 1) {
        // 处理 Derived1
    } else if (type == 2) {
        // 处理 Derived2
    }
}

int main() {
    const int ITERATIONS = 1000000;
    std::vector<Base*> objects;
    
    for (int i = 0; i < 1000; i++) {
        objects.push_back(i % 2 == 0 ? 
            static_cast<Base*>(new Derived1()) : 
            static_cast<Base*>(new Derived2()));
    }
    
    // 测试 RTTI 性能
    auto start1 = std::chrono::high_resolution_clock::now();
    for (int i = 0; i < ITERATIONS; i++) {
        for (Base* obj : objects) {
            processWithRTTI(obj);
        }
    }
    auto end1 = std::chrono::high_resolution_clock::now();
    auto duration1 = std::chrono::duration_cast<std::chrono::milliseconds>(end1 - start1);
    
    // 测试虚函数性能
    auto start2 = std::chrono::high_resolution_clock::now();
    for (int i = 0; i < ITERATIONS; i++) {
        for (Base* obj : objects) {
            processWithVirtual(obj);
        }
    }
    auto end2 = std::chrono::high_resolution_clock::now();
    auto duration2 = std::chrono::duration_cast<std::chrono::milliseconds>(end2 - start2);
    
    std::cout << "RTTI 方法耗时: " << duration1.count() << " ms
";
    std::cout << "虚函数方法耗时: " << duration2.count() << " ms
";
    
    for (Base* obj : objects) {
        delete obj;
    }
    
    return 0;
}
```

**性能建议：**
- `dynamic_cast` 有运行时开销，避免在性能关键路径中频繁使用
- `typeid` 通常比 `dynamic_cast` 快，但仍有开销
- 虚函数调用通常比 RTTI 更高效
- 如果可以用虚函数解决，就不要用 RTTI

## 5. RTTI 与设计模式

### 5.1 访问者模式的替代方案

```cpp
#include <iostream>
#include <vector>

// 不使用访问者模式，直接使用 RTTI
class Node {
public:
    virtual ~Node() {}
};

class TextNode : public Node {
private:
    std::string text;
public:
    TextNode(const std::string& t) : text(t) {}
    const std::string& getText() const { return text; }
};

class ImageNode : public Node {
private:
    std::string imageUrl;
public:
    ImageNode(const std::string& url) : imageUrl(url) {}
    const std::string& getImageUrl() const { return imageUrl; }
};

class HTMLRenderer {
public:
    void render(const std::vector<Node*>& nodes) {
        for (Node* node : nodes) {
            if (TextNode* textNode = dynamic_cast<TextNode*>(node)) {
                std::cout << "<p>" << textNode->getText() << "</p>
";
            } else if (ImageNode* imageNode = dynamic_cast<ImageNode*>(node)) {
                std::cout << "<img src="" << imageNode->getImageUrl() << "">
";
            }
        }
    }
};

int main() {
    std::vector<Node*> document = {
        new TextNode("Hello, World!"),
        new ImageNode("photo.jpg"),
        new TextNode("This is a paragraph.")
    };
    
    HTMLRenderer renderer;
    renderer.render(document);
    
    for (Node* node : document) {
        delete node;
    }
    
    return 0;
}
```

### 5.2 工厂模式中的类型检查

```cpp
#include <iostream>
#include <memory>
#include <typeinfo>

class Product {
public:
    virtual ~Product() {}
    virtual void use() = 0;
};

class ConcreteProductA : public Product {
public:
    void use() override {
        std::cout << "使用产品 A
";
    }
    void specialMethodA() {
        std::cout << "产品 A 的特殊方法
";
    }
};

class ConcreteProductB : public Product {
public:
    void use() override {
        std::cout << "使用产品 B
";
    }
    void specialMethodB() {
        std::cout << "产品 B 的特殊方法
";
    }
};

class Factory {
public:
    static std::unique_ptr<Product> createProduct(const std::string& type) {
        if (type == "A") {
            return std::make_unique<ConcreteProductA>();
        } else if (type == "B") {
            return std::make_unique<ConcreteProductB>();
        }
        return nullptr;
    }
};

void processProduct(Product* product) {
    product->use();  // 多态调用
    
    // 使用 RTTI 调用特定方法
    if (ConcreteProductA* prodA = dynamic_cast<ConcreteProductA*>(product)) {
        prodA->specialMethodA();
    } else if (ConcreteProductB* prodB = dynamic_cast<ConcreteProductB*>(product)) {
        prodB->specialMethodB();
    }
}

int main() {
    auto productA = Factory::createProduct("A");
    auto productB = Factory::createProduct("B");
    
    processProduct(productA.get());
    processProduct(productB.get());
    
    return 0;
}
```

## 6. 常见陷阱和注意事项

### 6.1 空指针检查

```cpp
#include <iostream>

class Base {
public:
    virtual ~Base() {}
};

class Derived : public Base {};

int main() {
    Base* ptr = nullptr;
    
    // ❌ 危险：对空指针使用 typeid 会抛出 std::bad_typeid
    try {
        std::cout << typeid(*ptr).name() << std::endl;
    } catch (std::bad_typeid& e) {
        std::cout << "错误: " << e.what() << std::endl;
    }
    
    // ✅ 安全：dynamic_cast 对空指针返回 nullptr
    Derived* d = dynamic_cast<Derived*>(ptr);
    if (d == nullptr) {
        std::cout << "转换失败（指针为空）
";
    }
    
    return 0;
}
```

### 6.2 多重继承的陷阱

```cpp
#include <iostream>

class Base1 {
public:
    virtual ~Base1() {}
};

class Base2 {
public:
    virtual ~Base2() {}
};

class Derived : public Base1, public Base2 {};

int main() {
    Derived* d = new Derived();
    
    // 向上转型到不同的基类
    Base1* b1 = d;
    Base2* b2 = d;
    
    std::cout << "d 地址: " << d << std::endl;
    std::cout << "b1 地址: " << b1 << std::endl;
    std::cout << "b2 地址: " << b2 << std::endl;  // 可能不同！
    
    // dynamic_cast 可以正确处理
    Derived* d1 = dynamic_cast<Derived*>(b1);
    Derived* d2 = dynamic_cast<Derived*>(b2);
    
    std::cout << "d1 地址: " << d1 << std::endl;
    std::cout << "d2 地址: " << d2 << std::endl;  // 都指向同一对象
    
    delete d;
    return 0;
}
```

### 6.3 虚继承与 RTTI

```cpp
#include <iostream>

class Animal {
public:
    virtual ~Animal() {}

class Mammal : virtual public Animal {};

class Bat : public Mammal, public Bird {};

";
```

### 6.4 const 正确性

```cpp
#include <iostream>

class Base {
public:
    virtual ~Base() {}
};

class Derived : public Base {
public:
    void modify() { std::cout << "修改对象
"; }
    void read() const { std::cout << "读取对象
"; }
};

int main() {
    const Base* constBase = new Derived();
    
    // ✅ 正确：转换为 const Derived*
    const Derived* constDerived = dynamic_cast<const Derived*>(constBase);
    if (constDerived) {
        constDerived->read();
        // constDerived->modify();  // 编译错误：const 对象不能调用非 const 方法
    }
    
    // ❌ 错误：不能去掉 const 限定符
    // Derived* derived = dynamic_cast<Derived*>(constBase);  // 编译错误
    
    delete constBase;
    return 0;
}
```

```cpp
        std::cout << "[文本消息] " << sender << " (" << timestamp << "): " 
                  << content << std::endl;
    }
    
    const std::string& getContent() const { return content; }
};

class ImageMessage : public Message {
private:
    std::string imageUrl;
    int width, height;
public:
    ImageMessage(const std::string& s, const std::string& t, 
                 const std::string& url, int w, int h)
        : Message(s, t), imageUrl(url), width(w), height(h) {}
    
    void display() const override {
        std::cout << "[图片消息] " << sender << " (" << timestamp << "): " 
                  << imageUrl << " [" << width << "x" << height << "]" << std::endl;
    }
    
    const std::string& getImageUrl() const { return imageUrl; }
    int getWidth() const { return width; }
    int getHeight() const { return height; }
};

    std::string audioUrl;
    int durationSeconds;
public:
    VoiceMessage(const std::string& s, const std::string& t,

        std::cout << "[语音消息] " << sender << " (" << timestamp << "): " 
                  << audioUrl << " [" << durationSeconds << "秒]" << std::endl;
    }
    
    const std::string& getAudioUrl() const { return audioUrl; }
    int getDuration() const { return durationSeconds; }
};

// ============= 消息处理器 =============
class MessageProcessor {
public:
    // 显示所有消息
    void displayAll(const std::vector<std::shared_ptr<Message>>& messages) {
        std::cout << "
=== 显示所有消息 ===
";
        for (const auto& msg : messages) {
            msg->display();  // 多态调用
        }
    }
    
    // 统计各类消息数量（使用 typeid）
    void analyzeMessages(const std::vector<std::shared_ptr<Message>>& messages) {
        int textCount = 0, imageCount = 0, voiceCount = 0;
        
        for (const auto& msg : messages) {
            if (typeid(*msg) == typeid(TextMessage)) {
                textCount++;
            } else if (typeid(*msg) == typeid(ImageMessage)) {
                imageCount++;
            } else if (typeid(*msg) == typeid(VoiceMessage)) {
                voiceCount++;
            }
        }
        
        std::cout << "
=== 消息统计 ===
";
        std::cout << "文本消息: " << textCount << " 条
";
        std::cout << "图片消息: " << imageCount << " 条
";
        std::cout << "语音消息: " << voiceCount << " 条
";
    }
    
    // 搜索文本内容（使用 dynamic_cast）
    void searchText(const std::vector<std::shared_ptr<Message>>& messages, 
                   const std::string& keyword) {
        std::cout << "
=== 搜索包含 "" << keyword << "" 的文本消息 ===
";
        bool found = false;
        
        for (const auto& msg : messages) {
            // 使用 dynamic_cast 安全地转换为 TextMessage
            if (TextMessage* textMsg = dynamic_cast<TextMessage*>(msg.get())) {
                if (textMsg->getContent().find(keyword) != std::string::npos) {
                    textMsg->display();
                    found = true;
                }
            }
        }
        
        if (!found) {
            std::cout << "未找到匹配的消息
";
        }
    }
    
    // 过滤大图片（使用 dynamic_cast）
    void filterLargeImages(const std::vector<std::shared_ptr<Message>>& messages, 
                          int minWidth, int minHeight) {
        std::cout << "
=== 尺寸大于 " << minWidth << "x" << minHeight 
                  << " 的图片消息 ===
";
        bool found = false;
        
        for (const auto& msg : messages) {
            if (ImageMessage* imgMsg = dynamic_cast<ImageMessage*>(msg.get())) {
                if (imgMsg->getWidth() >= minWidth && imgMsg->getHeight() >= minHeight) {
                    imgMsg->display();
                    found = true;
                }
            }
        }
        
        if (!found) {
            std::cout << "未找到符合条件的图片
";
        }
    }
    
    // 计算语音总时长（使用 dynamic_cast）
    int calculateTotalVoiceDuration(const std::vector<std::shared_ptr<Message>>& messages) {
        int totalDuration = 0;
        
        for (const auto& msg : messages) {
            if (VoiceMessage* voiceMsg = dynamic_cast<VoiceMessage*>(msg.get())) {
                totalDuration += voiceMsg->getDuration();
            }
        }
        
        return totalDuration;
    }
    
    // 按发送者过滤消息
    void filterBySender(const std::vector<std::shared_ptr<Message>>& messages, 
                       const std::string& sender) {
        std::cout << "
=== " << sender << " 发送的消息 ===
";
        bool found = false;
        
        for (const auto& msg : messages) {
            if (msg->getSender() == sender) {
                msg->display();  // 多态调用
                found = true;
            }
        }
        
        if (!found) {
            std::cout << "该用户未发送任何消息
";
        }
    }
};

// ============= 主函数 =============
int main() {
    // 创建消息列表
    std::vector<std::shared_ptr<Message>> messages;
    
    messages.push_back(std::make_shared<TextMessage>(
        "Alice", "2025-01-15 10:30", "大家好，今天天气不错！"));
    messages.push_back(std::make_shared<ImageMessage>(
        "Bob", "2025-01-15 10:32", "http://example.com/photo1.jpg", 1920, 1080));

        "Charlie", "2025-01-15 10:35", "我也觉得，适合出去玩！"));

    messages.push_back(std::make_shared<VoiceMessage>(
        "Charlie", "2025-01-15 10:55", "http://example.com/voice2.mp3", 8));

    MessageProcessor processor;
```

## 8. 知识点总结

| 概念 | 说明 | 使用场景 |
|------|------|----------|
| **RTTI** | 运行时类型信息机制 | 需要在运行时判断对象实际类型 |
| **dynamic_cast** | 安全的类型转换运算符 | 多态类型的向下转型、侧向转型 |
| **typeid** | 获取类型信息的运算符 | 类型比较、类型统计、日志调试 |
| **type_info** | 类型信息类 | 存储和比较类型信息 |
| **向下转型** | 基类指针转换为派生类指针 | 访问派生类特有成员 |
| **侧向转型** | 多重继承中的类型转换 | 在兄弟类之间转换 |
| **指针转换** | 失败返回 nullptr | 需要检查转换是否成功 |
| **引用转换** | 失败抛出 bad_cast 异常 | 确定转换会成功的场景 |

**关键要点：**

1. **RTTI 的前提条件**
   - 类必须是多态类型（至少有一个虚函数）
   - 编译器必须启用 RTTI 支持

2. **dynamic_cast 的特点**
   - 类型安全的转换
   - 运行时检查类型兼容性
   - 有性能开销

3. **typeid 的特点**
   - 返回类型信息对象
   - 可用于类型比较
   - 对空指针使用会抛出 bad_typeid 异常

4. **使用原则**
   - 优先使用虚函数而非 RTTI
   - 只在必要时使用 RTTI
   - 注意性能影响

5. **常见陷阱**
   - 空指针问题
   - 多重继承的地址问题
   - const 正确性
   - 过度依赖 RTTI
