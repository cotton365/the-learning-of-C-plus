## 1. Lambda 表达式基础

### 1.1 什么是 Lambda 表达式？

**Lambda 表达式**是 C++11 引入的一种创建匿名函数对象的简洁语法。

```cpp
#include <iostream>
#include <algorithm>
#include <vector>

int main() {
    std::vector<int> vec = {3, 1, 4, 1, 5, 9, 2, 6};
    
    // 传统方式：使用函数指针
    std::sort(vec.begin(), vec.end(), [](int a, int b) {
        return a < b;  // 升序排序
    });
    
    // Lambda 表达式：简洁、直观
    for (int n : vec) {
        std::cout << n << " ";
    }
    
    return 0;
}
```

### 1.2 Lambda 的完整语法

```cpp
[捕获列表] (参数列表) mutable(可选) 异常属性 -> 返回类型 { 函数体 }
```

**各部分说明：**

```cpp
#include <iostream>

int main() {
    int x = 10;
    int y = 20;
    
    // 完整语法示例
    auto lambda = [x, &y]           // 捕获列表
                  (int a, int b)    // 参数列表
                  mutable           // mutable 关键字
                  -> int            // 返回类型
                  {
                      x++;          // 可以修改捕获的 x（因为 mutable）
                      y++;          // 可以修改引用捕获的 y
                      return x + y + a + b;
                  };
    
    int result = lambda(5, 3);
    std::cout << "结果: " << result << std::endl;
    std::cout << "x = " << x << ", y = " << y << std::endl;
    
    return 0;
}
```

### 1.3 最简单的 Lambda

```cpp
#include <iostream>

int main() {
    // 1. 无参数、无捕获、无返回值
    auto hello = []() {
        std::cout << "Hello, Lambda!" << std::endl;
    };
    hello();
    
    // 2. 简化：省略参数列表的 ()
    auto hello2 = [] {
        std::cout << "Hello again!" << std::endl;
    };
    hello2();
    
    // 3. 有参数、有返回值
    auto add = [](int a, int b) {
        return a + b;  // 返回类型自动推导为 int
    };
    std::cout << "3 + 5 = " << add(3, 5) << std::endl;
    
    // 4. 显式指定返回类型
    auto divide = [](int a, int b) -> double {
        return static_cast<double>(a) / b;
    };
    std::cout << "10 / 3 = " << divide(10, 3) << std::endl;
    
    return 0;
}
```

## 2. 捕获列表详解

### 2.1 捕获列表的形式

| 捕获形式 | 说明 | 示例 |
|---------|------|------|
| `[]` | 不捕获任何变量 | `[](int x) { return x * 2; }` |
| `[x]` | 值捕获 x | `[x]() { return x; }` |
| `[&x]` | 引用捕获 x | `[&x]() { x++; }` |
| `[=]` | 值捕获所有外部变量 | `[=]() { return x + y; }` |
| `[&]` | 引用捕获所有外部变量 | `[&]() { x++; y++; }` |
| `[=, &x]` | 值捕获所有，x 引用捕获 | `[=, &x]() { x++; return y; }` |
| `[&, x]` | 引用捕获所有，x 值捕获 | `[&, x]() { y++; return x; }` |
| `[this]` | 捕获 this 指针 | `[this]() { return member; }` |
| `[*this]` | 拷贝当前对象（C++17） | `[*this]() { return member; }` |

### 2.2 值捕获 vs 引用捕获

```cpp
#include <iostream>

int main() {
    int x = 10;
    int y = 20;
    
    // 值捕获：拷贝变量的值
    auto lambda1 = [x, y]() {
        std::cout << "值捕获: x = " << x << ", y = " << y << std::endl;
        // x++;  // 错误！值捕获的变量是 const 的
    };
    
    x = 100;
    y = 200;
    lambda1();  // 输出: x = 10, y = 20（捕获时的值）
    
    // 引用捕获：捕获变量的引用
    auto lambda2 = [&x, &y]() {
        std::cout << "引用捕获: x = " << x << ", y = " << y << std::endl;
        x++;  // 可以修改
        y++;
    };
    
    lambda2();  // 输出: x = 100, y = 200（当前值）
    std::cout << "修改后: x = " << x << ", y = " << y << std::endl;  // x = 101, y = 201
    
    return 0;
}
```

### 2.3 隐式捕获

```cpp
#include <iostream>

int main() {
    int a = 1, b = 2, c = 3;
    
    // [=] 隐式值捕获所有使用到的变量
    auto lambda1 = [=]() {
        std::cout << "a = " << a << ", b = " << b << std::endl;
        // c 未使用，不会被捕获
    };
    
    // [&] 隐式引用捕获所有使用到的变量
    auto lambda2 = [&]() {
        a++;
        b++;
        std::cout << "a = " << a << ", b = " << b << std::endl;
    };
    
    lambda1();
    lambda2();
    
    // 混合捕获：默认值捕获，某些引用捕获
    auto lambda3 = [=, &a]() {
        std::cout << "a = " << a << ", b = " << b << std::endl;
        a++;  // 可以修改 a（引用捕获）
        // b++;  // 错误！b 是值捕获
    };
    
    lambda3();
    std::cout << "最终 a = " << a << std::endl;
    
    return 0;
}
```

### 2.4 捕获成员变量

```cpp
#include <iostream>

class Counter {
private:
    int count;
    
public:
    Counter() : count(0) {}
    
    void increment() {
        // 捕获 this 指针
        auto lambda1 = [this]() {
            count++;  // 访问成员变量
            std::cout << "Count: " << count << std::endl;
        };
        lambda1();
        
        // C++17: 捕获 *this（拷贝整个对象）
        auto lambda2 = [*this]() mutable {
            count++;  // 修改拷贝的对象
            std::cout << "Copy count: " << count << std::endl;
        };
        lambda2();
        std::cout << "Original count: " << count << std::endl;
    }
};

int main() {
    Counter c;
    c.increment();
    return 0;
}
```

## 3. mutable 关键字

### 3.1 为什么需要 mutable？

值捕获的变量默认是 `const` 的，不能修改。`mutable` 允许修改值捕获的变量。

```cpp
#include <iostream>

int main() {
    int x = 10;
    
    // ❌ 错误：不能修改值捕获的变量
    // auto lambda1 = [x]() {
    //     x++;  // 编译错误
    // };
    
    // ✅ 正确：使用 mutable
    auto lambda2 = [x]() mutable {
        x++;  // 可以修改捕获的副本
        std::cout << "Lambda 内: x = " << x << std::endl;
    };
    
    lambda2();  // 输出: 11
    lambda2();  // 输出: 12（持续累加）
    std::cout << "Lambda 外: x = " << x << std::endl;  // 输出: 10（原变量不变）
    
    return 0;
}
```

### 3.2 mutable 的应用场景

```cpp
#include <iostream>

int main() {
    int callCount = 0;
    
    // 计数器：记录 Lambda 被调用的次数
    auto counter = [callCount]() mutable {
        callCount++;
        std::cout << "调用次数: " << callCount << std::endl;
        return callCount;
    };
    
    counter();  // 1
    counter();  // 2
    counter();  // 3
    
    std::cout << "外部 callCount: " << callCount << std::endl;  // 0（未改变）
    
    return 0;
}
```

## 4. Lambda 与 STL 算法

### 4.1 排序和查找

```cpp
#include <iostream>
#include <algorithm>
#include <vector>

int main() {
    std::vector<int> vec = {5, 2, 8, 1, 9, 3, 7};
    
    // 1. 排序：降序
    std::sort(vec.begin(), vec.end(), [](int a, int b) {
        return a > b;
    });
    
    for (int n : vec) std::cout << n << " ";
    std::cout << std::endl;
    
    // 2. 查找：第一个大于 5 的元素
    auto it = std::find_if(vec.begin(), vec.end(), [](int n) {
        return n > 5;
    });
    
    if (it != vec.end()) {
        std::cout << "第一个大于 5 的元素: " << *it << std::endl;
    }
    
    // 3. 统计：偶数的个数
    int evenCount = std::count_if(vec.begin(), vec.end(), [](int n) {
        return n % 2 == 0;
    });
    std::cout << "偶数个数: " << evenCount << std::endl;
    
    return 0;
}
```

### 4.2 变换和过滤

```cpp
#include <iostream>
#include <algorithm>
#include <vector>

int main() {
    std::vector<int> vec = {1, 2, 3, 4, 5};
    
    // 1. 变换：每个元素乘以 2
    std::vector<int> result(vec.size());
    std::transform(vec.begin(), vec.end(), result.begin(), [](int n) {
        return n * 2;
    });
    
    std::cout << "变换后: ";
    for (int n : result) std::cout << n << " ";
    std::cout << std::endl;
    
    // 2. 过滤：移除奇数
    auto newEnd = std::remove_if(vec.begin(), vec.end(), [](int n) {
        return n % 2 != 0;
    });
    vec.erase(newEnd, vec.end());
    
    std::cout << "过滤后: ";
    for (int n : vec) std::cout << n << " ";
    std::cout << std::endl;
    
    return 0;
}
```

### 4.3 累积和聚合

```cpp
#include <iostream>
#include <numeric>
#include <vector>

int main() {
    std::vector<int> vec = {1, 2, 3, 4, 5};
    
    // 1. 求和
    int sum = std::accumulate(vec.begin(), vec.end(), 0, [](int acc, int n) {
        return acc + n;
    });
    std::cout << "求和: " << sum << std::endl;
    
    // 2. 求积
    int product = std::accumulate(vec.begin(), vec.end(), 1, [](int acc, int n) {
        return acc * n;
    });
    std::cout << "求积: " << product << std::endl;
    
    // 3. 自定义聚合：拼接字符串
    std::vector<std::string> words = {"Hello", "World", "from", "Lambda"};
    std::string sentence = std::accumulate(
        words.begin(), words.end(), std::string(""),
        [](const std::string& acc, const std::string& word) {
            return acc.empty() ? word : acc + " " + word;
        }
    );
    std::cout << "句子: " << sentence << std::endl;
    
    return 0;
}
```

## 5. 泛型 Lambda（C++14）

### 5.1 使用 auto 参数

C++14 允许在 Lambda 参数中使用 `auto`，创建泛型 Lambda：

```cpp
#include <iostream>
#include <string>
#include <vector>

int main() {
    // 泛型 Lambda：接受任意类型
    auto print = [](const auto& value) {
        std::cout << value << std::endl;
    };
    
    print(42);           // int
    print(3.14);         // double
    print("Hello");      // const char*
    print(std::string("World"));  // std::string
    
    // 泛型 Lambda：通用加法
    auto add = [](auto a, auto b) {
        return a + b;
    };
    
    std::cout << add(1, 2) << std::endl;         // int
    std::cout << add(1.5, 2.5) << std::endl;     // double
    std::cout << add(std::string("Hello"), std::string(" World")) << std::endl;
    
    return 0;
}
```

### 5.2 泛型 Lambda 的应用

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

int main() {

            std::cout << elem << " ";
        }
        std::cout << "]" << std::endl;
    };
    
    std::vector<int> vec = {1, 2, 3, 4, 5};
    std::vector<std::string> words = {"Hello", "World"};
    
    printContainer(vec);

}
```

## 6. Lambda 的本质：闭包

### 6.1 Lambda 是函数对象

编译器将 Lambda 表达式转换为函数对象（闭包类型）：

```cpp
#include <iostream>

int main() {
    int x = 10;
    
    // Lambda 表达式
    auto lambda = [x](int y) {
        return x + y;
    };
    
    // 编译器生成的等价代码（简化）：
    class __Lambda {
    private:
        int x;  // 捕获的变量成为成员变量
    public:
        __Lambda(int x_) : x(x_) {}
        
        int operator()(int y) const {  // operator() 成为调用运算符
            return x + y;
        }
    };
    
    __Lambda lambda2(x);
    
    std::cout << "lambda(5) = " << lambda(5) << std::endl;
    std::cout << "lambda2(5) = " << lambda2(5) << std::endl;
    
    return 0;
}
```

### 6.2 Lambda 的类型

每个 Lambda 表达式都有唯一的类型：

```cpp
#include <iostream>
#include <functional>

int main() {
    auto lambda1 = [](int x) { return x * 2; };
    auto lambda2 = [](int x) { return x * 2; };  // 不同的类型！
    
    // lambda1 = lambda2;  // 编译错误：类型不同
    
    // 使用 std::function 统一类型
    std::function<int(int)> func1 = lambda1;
    std::function<int(int)> func2 = lambda2;
    func1 = func2;  // 可以赋值
    
    std::cout << "func1(5) = " << func1(5) << std::endl;
    std::cout << "func2(5) = " << func2(5) << std::endl;
    
    return 0;
}
```

## 7. Lambda 的高级用法

### 7.1 递归 Lambda

```cpp
#include <iostream>
#include <functional>

int main() {
    // 使用 std::function 实现递归
    std::function<int(int)> factorial = [&factorial](int n) {
        return n <= 1 ? 1 : n * factorial(n - 1);
    };
    
    std::cout << "5! = " << factorial(5) << std::endl;
    
    // 斐波那契数列
    std::function<int(int)> fibonacci = [&fibonacci](int n) {
        return n <= 1 ? n : fibonacci(n - 1) + fibonacci(n - 2);
    };
    
    std::cout << "fibonacci(10) = " << fibonacci(10) << std::endl;
    
    return 0;
}
```

### 7.2 立即调用的 Lambda（IIFE）

```cpp
#include <iostream>

int main() {
    // 立即调用的 Lambda 表达式
    int result = [](int a, int b) {
        return a * a + b * b;
    }(3, 4);  // 立即调用，传入参数 3 和 4
    
    std::cout << "结果: " << result << std::endl;
    
    // 用于复杂初始化
    const int value = []() {
        int sum = 0;
        for (int i = 1; i <= 10; ++i) {
            sum += i;
        }
        return sum;
    }();
    
    std::cout << "1 到 10 的和: " << value << std::endl;
    
    return 0;
}
```

### 7.3 Lambda 作为返回值

```cpp
#include <iostream>
#include <functional>

// 返回一个 Lambda
std::function<int(int)> makeMultiplier(int factor) {
    return [factor](int x) {
        return x * factor;
    };
}

// 返回一个累加器
std::function<int()> makeAccumulator(int start) {
    return [sum = start]() mutable {
        return sum++;
    };
}

int main() {
    auto times2 = makeMultiplier(2);
    auto times5 = makeMultiplier(5);
    
    std::cout << "10 * 2 = " << times2(10) << std::endl;
    std::cout << "10 * 5 = " << times5(10) << std::endl;
    
    auto counter = makeAccumulator(0);
    std::cout << counter() << std::endl;  // 0
    std::cout << counter() << std::endl;  // 1
    std::cout << counter() << std::endl;  // 2
    
    return 0;
}
```

## 8. Lambda 的常见陷阱

### 8.1 陷阱1：悬空引用

```cpp
#include <iostream>
#include <functional>

std::function<void()> createLambda() {
    int x = 10;
    
    // ❌ 危险：返回捕获局部变量引用的 Lambda
    return [&x]() {
        std::cout << "x = " << x << std::endl;  // x 已经被销毁！
    };
}

int main() {
    auto lambda = createLambda();
    lambda();  // 未定义行为：访问已销毁的变量
    
    return 0;
}
```

**解决方案：**

```cpp
std::function<void()> createLambdaSafe() {
    int x = 10;
    
    // ✅ 安全：值捕获
    return [x]() {
        std::cout << "x = " << x << std::endl;
    };
}
```

### 8.2 陷阱2：意外的值捕获

```cpp
#include <iostream>
#include <vector>

int main() {
    std::vector<std::function<void()>> lambdas;
    
    // ❌ 错误：值捕获循环变量
    for (int i = 0; i < 5; ++i) {
        lambdas.push_back([i]() {
            std::cout << i << " ";
        });
    }
    
    for (auto& lambda : lambdas) {
        lambda();  // 输出: 0 1 2 3 4（正确）
    }
    std::cout << std::endl;
    
    // ❌ 如果用引用捕获会怎样？
    std::vector<std::function<void()>> lambdas2;
    for (int i = 0; i < 5; ++i) {
        lambdas2.push_back([&i]() {
            std::cout << i << " ";
        });
    }
    
    for (auto& lambda : lambdas2) {
        lambda();  // 输出: 5 5 5 5 5（所有 Lambda 都引用同一个 i）
    }
    std::cout << std::endl;
    
    return 0;
}
```

### 8.3 陷阱3：不必要的拷贝

```cpp
#include <iostream>
#include <vector>

int main() {
    std::vector<int> largeVec(1000000, 42);
    
    // ❌ 不好：值捕获大对象
    auto lambda1 = [largeVec]() {
        return largeVec.size();  // 拷贝了整个 vector！
    };
    
    // ✅ 好：引用捕获
    auto lambda2 = [&largeVec]() {
        return largeVec.size();
    };
    
    // ✅ 或者使用 const 引用
    const auto& vecRef = largeVec;
    auto lambda3 = [&vecRef]() {
        return vecRef.size();
    };
    
    return 0;
}
```

## 9. Lambda 的最佳实践

### 9.1 选择合适的捕获方式

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

void processData(const std::vector<int>& data) {
    int threshold = 50;
    int count = 0;
    
    // ✅ 好：明确捕获需要的变量
    std::for_each(data.begin(), data.end(), [threshold, &count](int value) {
        if (value > threshold) {
            count++;
        }
    });
    
    // ❌ 不好：隐式捕获所有
    // std::for_each(data.begin(), data.end(), [=, &count](int value) {
    //     if (value > threshold) {
    //         count++;
    //     }
    // });
    
    std::cout << "Count: " << count << std::endl;
}

int main() {
    std::vector<int> data = {10, 30, 50, 70, 90};
    processData(data);
    return 0;
}
```

### 9.2 保持 Lambda 简短

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

int main() {
    std::vector<int> vec = {1, 2, 3, 4, 5};
    
    // ✅ 好：简短的 Lambda
    int sum = 0;
    std::for_each(vec.begin(), vec.end(), [&sum](int n) {
        sum += n;
    });
    
    // ❌ 不好：过长的 Lambda（应该提取为函数）
    std::vector<int> result;
    std::transform(vec.begin(), vec.end(), std::back_inserter(result), 
        [](int n) {
            // 复杂的逻辑...
            int temp = n * 2;
            if (temp > 5) {
                temp += 10;
            } else {
                temp *= 3;
            }
            return temp;
        }
    );
    
    return 0;
}
```

### 9.3 使用泛型 Lambda 提高复用性

```cpp
#include <iostream>
#include <vector>
#include <string>

int main() {
    // ✅ 泛型 Lambda：适用于多种类型
    auto printer = [](const auto& container, const std::string& name) {
        std::cout << name << ": ";
        for (const auto& item : container) {
            std::cout << item << " ";
        }
        std::cout << std::endl;
    };
    
    std::vector<int> numbers = {1, 2, 3, 4, 5};
    std::vector<std::string> words = {"Hello", "World"};
    
    printer(numbers, "Numbers");
    printer(words, "Words");
    
    return 0;
}
```

## 10. 实战案例：事件处理系统

```cpp
#include <iostream>
#include <functional>
#include <vector>
#include <string>
#include <algorithm>

// 事件类型
enum class EventType {
    CLICK,
    KEYPRESS,
    MOUSE_MOVE
};

// 事件数据
struct Event {
    EventType type;
    int x, y;
    char key;
};

// 事件处理器管理器
class EventHandler {
private:
    using Handler = std::function<void(const Event&)>;
    std::vector<Handler> handlers;
    
public:
    // 添加事件处理器
    void addHandler(Handler handler) {
        handlers.push_back(handler);
    }
    
    // 触发事件
    void trigger(const Event& event) {
        for (auto& handler : handlers) {
            handler(event);
        }
    }
    
    // 移除所有处理器
    void clear() {
        handlers.clear();
    }
};

int main() {
    EventHandler eventHandler;
    
    // 添加点击事件处理器
    eventHandler.addHandler([](const Event& e) {
        if (e.type == EventType::CLICK) {
            std::cout << "点击事件: (" << e.x << ", " << e.y << ")" << std::endl;
        }
    });
    
    // 添加键盘事件处理器
    eventHandler.addHandler([](const Event& e) {
        if (e.type == EventType::KEYPRESS) {
            std::cout << "按键事件: " << e.key << std::endl;
        }
    });
    
    // 添加鼠标移动事件处理器（带状态）
    int moveCount = 0;
    eventHandler.addHandler([&moveCount](const Event& e) {
        if (e.type == EventType::MOUSE_MOVE) {
            moveCount++;
            std::cout << "鼠标移动事件 #" << moveCount 
                      << ": (" << e.x << ", " << e.y << ")" << std::endl;
        }
    });
    
    // 触发不同事件
    std::cout << "=== 触发事件 ===
";
    eventHandler.trigger({EventType::CLICK, 100, 200, ' '});
    eventHandler.trigger({EventType::KEYPRESS, 0, 0, 'A'});
    eventHandler.trigger({EventType::MOUSE_MOVE, 150, 250, ' '});
    eventHandler.trigger({EventType::MOUSE_MOVE, 160, 260, ' '});
    
    std::cout << "
总移动次数: " << moveCount << std::endl;
    
    return 0;
}
```

## 11. 知识点总结

| 概念 | 说明 | 示例 |
|------|------|------|
| **基本语法** | `[捕获](参数) { 函数体 }` | `[](int x) { return x * 2; }` |
| **值捕获** | 拷贝变量的值 | `[x]() { return x; }` |
| **引用捕获** | 捕获变量的引用 | `[&x]() { x++; }` |
| **隐式捕获** | 自动捕获使用的变量 | `[=]()` 或 `[&]()` |
| **mutable** | 允许修改值捕获的变量 | `[x]() mutable { x++; }` |
| **返回类型** | 自动推导或显式指定 | `[](int x) -> double { ... }` |
| **泛型 Lambda** | 使用 auto 参数（C++14） | `[](auto x) { return x * 2; }` |
| **闭包** | Lambda 的本质是函数对象 | 编译器生成类 |

**核心要点：**

1. **Lambda 的优势**
   - 语法简洁，代码清晰
   - 捕获外部变量，形成闭包
   - 与 STL 算法完美配合
   - 减少命名污染

2. **捕获规则**
   - 值捕获：拷贝，不可修改（除非 mutable）
   - 引用捕获：可修改，但要注意生命周期
   - 隐式捕获：方便但要小心捕获过多
   - 明确捕获：更清晰、更安全

3. **使用场景**
   - STL 算法的谓词
   - 回调函数
   - 延迟计算
   - 事件处理
   - 配置和初始化

4. **注意事项**
   - 避免悬空引用
   - 注意大对象的拷贝开销
   - 保持 Lambda 简短
   - 明确捕获比隐式捕获更安全

### 练习 2：实现一个简单的函数式编程库（中等）

**题目描述：**

使用 Lambda 表达式实现一个简单的函数式编程工具集，包括 map、filter、reduce 等操作。

**要求：**

1. 实现以下函数模板：
   ```cpp
   // map: 对每个元素应用转换函数
   template<typename Container, typename Func>
   auto map(const Container& container, Func func);
   
   // filter: 过滤满足条件的元素
   template<typename Container, typename Pred>
   auto filter(const Container& container, Pred pred);
   
   // reduce: 将元素聚合为单个值
   template<typename Container, typename T, typename Func>
   T reduce(const Container& container, T init, Func func);
   ```

2. 实现链式调用：
   ```cpp
   auto result = map(filter(data, [](int x) { return x > 0; }),
                     [](int x) { return x * 2; });
   ```

3. 编写测试用例，展示：
   - 将数组中所有元素乘以 2
   - 过滤出所有正数
   - 计算所有元素的和与积
   - 链式调用：过滤 → 变换 → 聚合

4. 额外挑战：实现一个 `compose` 函数，组合多个 Lambda

**提示：**
- 使用 `std::transform`、`std::copy_if`、`std::accumulate`
- 返回类型可以使用 `auto` 或 `decltype`
- 考虑使用泛型 Lambda（C++14）

**测试用例：**
```cpp
std::vector<int> data = {-2, -1, 0, 1, 2, 3, 4, 5};

// map: 每个元素乘以 2
auto doubled = map(data, [](int x) { return x * 2; });

// filter: 只保留正数
auto positives = filter(data, [](int x) { return x > 0; });

// reduce: 求和
int sum = reduce(data, 0, [](int acc, int x) { return acc + x; });

// 链式调用：过滤正数 → 乘以 2 → 求和
int result = reduce(
    map(filter(data, [](int x) { return x > 0; }),
        [](int x) { return x * 2; }),
    0,
    [](int acc, int x) { return acc + x; }
);
```

**期望输出：**
```

Doubled: -4 -2 0 2 4 6 8 10
Positives: 1 2 3 4 5
Sum: 12
链式结果: 30  // (1+2+3+4+5) * 2
```

### 练习 3：实现一个基于 Lambda 的异步任务调度器（高级）

**题目描述：**

设计并实现一个任务调度器，支持添加、执行、取消任务，所有任务都使用 Lambda 表达式定义。

**要求：**

1. **核心功能：**
   - `addTask(lambda)` - 添加任务到队列
   - `addDelayedTask(lambda, delay)` - 添加延迟任务
   - `addRepeatingTask(lambda, interval)` - 添加重复任务
   - `execute()` - 执行所有到期的任务
   - `cancelTask(id)` - 取消指定任务
   - `clear()` - 清空所有任务

2. **任务类型：**
   - 立即任务：立即执行
   - 延迟任务：在指定时间后执行一次
   - 重复任务：每隔指定时间执行一次

3. **任务管理：**
   - 每个任务有唯一 ID
   - 任务可以捕获外部变量
   - 支持任务优先级（可选）
   - 统计任务执行次数

4. **实现细节：**
   ```cpp
   class TaskScheduler {
   private:
       using Task = std::function<void()>;
       
       struct TaskInfo {
           int id;
           Task task;
           long long executeTime;  // 执行时间（毫秒）
           long long interval;     // 重复间隔（0 表示不重复）
           bool cancelled;
       };
       
       std::vector<TaskInfo> tasks;
       int nextId = 1;
       
   public:
       int addTask(Task task);
       int addDelayedTask(Task task, long long delayMs);
       int addRepeatingTask(Task task, long long intervalMs);
       void execute();
       void cancelTask(int id);
       void clear();
       void printStatus();
   };
   ```

5. **测试场景：**
   - 创建多个不同类型的任务
   - 任务之间有依赖关系（一个任务完成后启动另一个）
   - 任务可以修改共享状态
   - 测试任务取消功能
   - 模拟时间推进，验证延迟和重复任务

**提示：**
- 使用 `std::chrono` 处理时间
- 任务队列可以用 `std::vector` 或 `std::priority_queue`
- 注意 Lambda 捕获的线程安全问题（可以忽略，假设单线程）
- 可以使用 mutable Lambda 维护任务状态

**测试用例：**
```cpp

    std::cout << "立即任务执行
";

// 延迟任务（1000ms 后）

int task2 = scheduler.addDelayedTask([&counter]() {

";

";

}

// 取消重复任务
scheduler.cancelTask(task3);
std::cout << "
=== 取消重复任务后 ===
";
scheduler.execute();

// 打印状态
scheduler.printStatus();
```
