## 1. 特殊成员函数概述

### 1.1 什么是特殊成员函数？

C++ 类有六个特殊成员函数（编译器可能自动生成）：

```cpp
class MyClass {
public:
    // 1. 默认构造函数
    MyClass();
    
    // 2. 析构函数
    ~MyClass();
    
    // 3. 拷贝构造函数
    MyClass(const MyClass& other);
    
    // 4. 拷贝赋值运算符
    MyClass& operator=(const MyClass& other);
    
    // 5. 移动构造函数 (C++11)
    MyClass(MyClass&& other) noexcept;
    
    // 6. 移动赋值运算符 (C++11)
    MyClass& operator=(MyClass&& other) noexcept;
};
```

### 1.2 编译器自动生成规则

编译器在某些情况下会自动生成这些函数：

```cpp
#include <iostream>

class Simple {
    int value;
    // 编译器自动生成所有六个特殊成员函数
};

int main() {
    Simple s1;              // 默认构造
    Simple s2 = s1;         // 拷贝构造
    Simple s3;
    s3 = s1;                // 拷贝赋值
    Simple s4 = std::move(s1);  // 移动构造
    s3 = std::move(s2);     // 移动赋值
    
    return 0;
}  // 析构
```

**自动生成的条件：**

| 函数 | 何时自动生成 | 何时被禁止生成 |
|------|------------|--------------|
| 默认构造函数 | 没有声明任何构造函数 | 声明了任何构造函数 |
| 析构函数 | 总是生成（如果未声明） | 用户声明了析构函数 |
| 拷贝构造 | 未声明拷贝构造 | 声明了移动操作 |
| 拷贝赋值 | 未声明拷贝赋值 | 声明了移动操作 |
| 移动构造 | 未声明拷贝、移动、析构 | 声明了拷贝、移动或析构 |
| 移动赋值 | 未声明拷贝、移动、析构 | 声明了拷贝、移动或析构 |

## 2. 三法则（Rule of Three）

### 2.1 三法则的定义

**三法则：** 如果一个类需要自定义以下三者之一，那么它很可能需要自定义全部三个：
1. 析构函数
2. 拷贝构造函数
3. 拷贝赋值运算符

### 2.2 为什么需要三法则？

当类管理资源（动态内存、文件句柄、网络连接等）时，必须正确处理：

```cpp
#include <iostream>
#include <cstring>

// ❌ 错误示例：违反三法则
class BadString {
private:
    char* data;
    
public:
    BadString(const char* str) {
        data = new char[strlen(str) + 1];
        strcpy(data, str);
    }
    
    // 只定义了析构函数，没有定义拷贝操作
    ~BadString() {
        delete[] data;
    }
    
    // 编译器生成的拷贝构造和拷贝赋值是浅拷贝！
};

int main() {
    BadString s1("Hello");
    BadString s2 = s1;  // 浅拷贝！两个对象共享同一个 data
    
    // 程序结束时，data 被释放两次 → 崩溃！
    return 0;
}
```

**问题分析：**
- `s1` 和 `s2` 的 `data` 指向同一块内存
- 当 `s2` 析构时，释放了内存
- 当 `s1` 析构时，再次释放同一块内存 → 双重释放（double free）

### 2.3 正确实现三法则

```cpp
#include <iostream>
#include <cstring>

class GoodString {
private:
    char* data;
    size_t length;
    
public:
    // 构造函数
    GoodString(const char* str = "") {
        length = strlen(str);
        data = new char[length + 1];
        strcpy(data, str);
        std::cout << "构造: "" << data << ""
";
    }
    
    // 1️⃣ 析构函数
    ~GoodString() {
        std::cout << "析构: "" << (data ? data : "null") << ""
";
        delete[] data;
    }
    
    // 2️⃣ 拷贝构造函数（深拷贝）
    GoodString(const GoodString& other) {
        length = other.length;
        data = new char[length + 1];
        strcpy(data, other.data);
        std::cout << "拷贝构造: "" << data << ""
";
    }
    
    // 3️⃣ 拷贝赋值运算符（深拷贝）
    GoodString& operator=(const GoodString& other) {
        std::cout << "拷贝赋值: "" << other.data << ""
";
        
        if (this != &other) {  // 自赋值检查
            // 释放旧资源
            delete[] data;
            
            // 分配新资源
            length = other.length;
            data = new char[length + 1];
            strcpy(data, other.data);
        }
        return *this;
    }
    
    const char* c_str() const { return data; }
};

int main() {
    GoodString s1("Hello");
    GoodString s2 = s1;      // 拷贝构造
    GoodString s3("World");
    s3 = s1;                 // 拷贝赋值
    
    std::cout << "s1: " << s1.c_str() << "
";
    std::cout << "s2: " << s2.c_str() << "
";
    std::cout << "s3: " << s3.c_str() << "
";
    
    return 0;
}
```

### 2.4 三法则的经典应用场景

```cpp
#include <iostream>

// 示例：文件句柄管理
class FileHandle {
private:
    FILE* file;
    char* filename;
    
public:
    FileHandle(const char* name) {
        filename = new char[strlen(name) + 1];
        strcpy(filename, name);
        file = fopen(filename, "w");
        std::cout << "打开文件: " << filename << "
";
    }
    
    ~FileHandle() {
        if (file) {
            fclose(file);
            std::cout << "关闭文件: " << filename << "
";
        }
        delete[] filename;
    }
    
    // 拷贝构造：创建新文件句柄
    FileHandle(const FileHandle& other) {
        filename = new char[strlen(other.filename) + 1];
        strcpy(filename, other.filename);
        file = fopen(filename, "w");
        std::cout << "拷贝文件句柄: " << filename << "
";
    }
    
    // 拷贝赋值
    FileHandle& operator=(const FileHandle& other) {
        if (this != &other) {
            // 关闭旧文件
            if (file) fclose(file);
            delete[] filename;
            
            // 打开新文件
            filename = new char[strlen(other.filename) + 1];
            strcpy(filename, other.filename);
            file = fopen(filename, "w");
            std::cout << "赋值文件句柄: " << filename << "
";
        }
        return *this;
    }
    
    void write(const char* content) {
        if (file) {
            fprintf(file, "%s", content);
        }
    }
};
```

## 3. 五法则（Rule of Five）

### 3.1 五法则的定义

**五法则：** C++11 引入移动语义后，如果需要自定义以下五者之一，应该考虑自定义全部五个：
1. 析构函数
2. 拷贝构造函数
3. 拷贝赋值运算符
4. 移动构造函数
5. 移动赋值运算符

### 3.2 为什么需要五法则？

移动语义提供了更高效的资源转移方式：

```cpp
#include <iostream>
#include <cstring>
#include <utility>

class ModernString {
private:
    char* data;
    size_t length;
    
public:
    // 构造函数
    ModernString(const char* str = "") {
        length = strlen(str);
        data = new char[length + 1];
        strcpy(data, str);
        std::cout << "构造: "" << data << ""
";
    }
    
    // 1️⃣ 析构函数
    ~ModernString() {
        std::cout << "析构: "" << (data ? data : "null") << ""
";
        delete[] data;
    }
    
    // 2️⃣ 拷贝构造函数
    ModernString(const ModernString& other) {
        length = other.length;
        data = new char[length + 1];
        strcpy(data, other.data);
        std::cout << "拷贝构造: "" << data << ""
";
    }
    
    // 3️⃣ 拷贝赋值运算符
    ModernString& operator=(const ModernString& other) {
        std::cout << "拷贝赋值: "" << other.data << ""
";
        if (this != &other) {
            delete[] data;
            length = other.length;
            data = new char[length + 1];
            strcpy(data, other.data);
        }
        return *this;
    }
    
    // 4️⃣ 移动构造函数
    ModernString(ModernString&& other) noexcept {
        std::cout << "移动构造: "" << other.data << ""
";
        data = other.data;
        length = other.length;
        other.data = nullptr;
        other.length = 0;
    }
    
    // 5️⃣ 移动赋值运算符
    ModernString& operator=(ModernString&& other) noexcept {
        std::cout << "移动赋值: "" << other.data << ""
";
        if (this != &other) {
            delete[] data;
            data = other.data;
            length = other.length;
            other.data = nullptr;
            other.length = 0;
        }
        return *this;
    }
    
    const char* c_str() const { return data ? data : ""; }
};

ModernString createString(const char* str) {
    return ModernString(str);
}

int main() {
    std::cout << "=== 拷贝操作 ===
";
    ModernString s1("Hello");
    ModernString s2 = s1;  // 拷贝构造
    
    std::cout << "
=== 移动操作 ===
";
    ModernString s3 = createString("World");  // 移动构造
    
    std::cout << "
=== std::move 强制移动 ===
";
    ModernString s4 = std::move(s1);  // 移动构造
    
    std::cout << "
s1: "" << s1.c_str() << ""  (被移动)
";
    std::cout << "s4: "" << s4.c_str() << ""
";
    
    return 0;
}
```

### 3.3 五法则的实现模板

```cpp
class Resource {
private:
    ResourceType* resource;
    
public:
    // 构造函数
    Resource() : resource(nullptr) {}
    
    // 1. 析构函数
    ~Resource() {
        cleanup();
    }
    
    // 2. 拷贝构造函数
    Resource(const Resource& other) {
        if (other.resource) {
            resource = new ResourceType(*other.resource);
        } else {
            resource = nullptr;
        }
    }
    
    // 3. 拷贝赋值运算符
    Resource& operator=(const Resource& other) {
        if (this != &other) {
            cleanup();
            if (other.resource) {
                resource = new ResourceType(*other.resource);
            } else {
                resource = nullptr;
            }
        }
        return *this;
    }
    
    // 4. 移动构造函数
    Resource(Resource&& other) noexcept
        : resource(other.resource) {
        other.resource = nullptr;
    }
    
    // 5. 移动赋值运算符
    Resource& operator=(Resource&& other) noexcept {
        if (this != &other) {
            cleanup();
            resource = other.resource;
            other.resource = nullptr;
        }
        return *this;
    }
    
private:
    void cleanup() {
        delete resource;
        resource = nullptr;
    }
};
```

## 4. 零法则（Rule of Zero）

### 4.1 零法则的定义

**零法则：** 如果可以避免自定义特殊成员函数，就不要自定义它们。让编译器生成默认实现，使用 RAII 封装的类型管理资源。

### 4.2 零法则的实现

```cpp
#include <iostream>
#include <string>
#include <vector>
#include <memory>

// ❌ 不好的设计：手动管理资源
class BadEmployee {
private:
    char* name;
    int* salary;
    
public:
    BadEmployee(const char* n, int s) {
        name = new char[strlen(n) + 1];
        strcpy(name, n);
        salary = new int(s);
    }
    
    // 需要自定义所有五个特殊成员函数
    ~BadEmployee() {
        delete[] name;
        delete salary;
    }
    
    BadEmployee(const BadEmployee& other) { /* ... */ }
    BadEmployee& operator=(const BadEmployee& other) { /* ... */ }
    BadEmployee(BadEmployee&& other) noexcept { /* ... */ }
    BadEmployee& operator=(BadEmployee&& other) noexcept { /* ... */ }
};

// ✅ 好的设计：使用 RAII 类型
class GoodEmployee {
private:
    std::string name;      // 自动管理内存
    int salary;            // 值类型，无需特殊处理
    
public:
    GoodEmployee(const std::string& n, int s) 
        : name(n), salary(s) {}
    
    // 不需要自定义任何特殊成员函数！
    // 编译器生成的默认实现是正确的
};

int main() {
    GoodEmployee e1("Alice", 50000);
    GoodEmployee e2 = e1;              // 拷贝：正确
    GoodEmployee e3 = std::move(e1);   // 移动：高效
    
    return 0;
}
```

### 4.3 零法则的优势

```cpp
#include <string>
#include <vector>
#include <memory>

// 复杂的数据结构，但不需要自定义特殊成员函数
class Student {
private:
    std::string name;
    std::vector<int> scores;
    std::unique_ptr<std::string> nickname;
    
public:
    Student(const std::string& n) : name(n) {}
    
    void addScore(int score) {
        scores.push_back(score);
    }
    
    void setNickname(const std::string& nick) {
        nickname = std::make_unique<std::string>(nick);
    }
    
    // 所有特殊成员函数由编译器正确生成！
    // - string 和 vector 自动深拷贝
    // - unique_ptr 禁止拷贝，支持移动
};

int main() {
    Student s1("Bob");
    s1.addScore(90);
    
    // Student s2 = s1;  // 编译错误：unique_ptr 禁止拷贝
    Student s3 = std::move(s1);  // 移动：正确
    
    return 0;
}
```

### 4.4 何时使用零法则

```cpp
#include <string>
#include <vector>
#include <fstream>

// ✅ 零法则：使用标准库类型
class Logger {
private:
    std::string filename;
    std::ofstream file;
    std::vector<std::string> buffer;
    
public:
    Logger(const std::string& name) : filename(name), file(name) {}
    
    void log(const std::string& message) {
        file << message << std::endl;
        buffer.push_back(message);
    }
    
    // ofstream 不可拷贝，但可移动
    // 编译器自动生成正确的特殊成员函数
};

// ❌ 需要五法则：直接管理 C 资源
class CStyleLogger {
private:
    char* filename;
    FILE* file;
    
public:
    CStyleLogger(const char* name) {
        filename = new char[strlen(name) + 1];
        strcpy(filename, name);
        file = fopen(filename, "w");
    }
    
    // 必须自定义所有五个特殊成员函数
    ~CStyleLogger() {
        if (file) fclose(file);
        delete[] filename;
    }
    // ... 其他四个
};
```

## 5. = default 和 = delete

### 5.1 = default：显式默认

`= default` 告诉编译器生成默认实现：

```cpp
#include <iostream>

class MyClass {
private:
    int value;
    
public:
    // 显式声明默认构造函数
    MyClass() = default;
    
    // 自定义构造函数
    MyClass(int v) : value(v) {}
    
    // 显式声明默认拷贝构造
    MyClass(const MyClass&) = default;
    
    // 显式声明默认拷贝赋值
    MyClass& operator=(const MyClass&) = default;
    
    // 显式声明默认移动构造
    MyClass(MyClass&&) = default;
    
    // 显式声明默认移动赋值
    MyClass& operator=(MyClass&&) = default;
    
    // 显式声明默认析构
    ~MyClass() = default;
};

int main() {
    MyClass obj1;           // 使用默认构造
    MyClass obj2(42);       // 使用自定义构造
    MyClass obj3 = obj2;    // 使用默认拷贝构造
    
    return 0;
}
```

### 5.2 = delete：禁用函数

`= delete` 明确禁止某些操作：

```cpp
#include <iostream>

// 不可拷贝的类
class NonCopyable {
private:
    int* data;
    
public:
    NonCopyable(int value) : data(new int(value)) {}
    
    ~NonCopyable() {
        delete data;
    }
    
    // 禁用拷贝操作
    NonCopyable(const NonCopyable&) = delete;
    NonCopyable& operator=(const NonCopyable&) = delete;
    
    // 允许移动操作
    NonCopyable(NonCopyable&& other) noexcept : data(other.data) {
        other.data = nullptr;
    }
    
    NonCopyable& operator=(NonCopyable&& other) noexcept {
        if (this != &other) {
            delete data;
            data = other.data;
            other.data = nullptr;
        }
        return *this;
    }
};

int main() {
    NonCopyable obj1(42);
    
    // NonCopyable obj2 = obj1;  // 编译错误：拷贝被禁用
    NonCopyable obj3 = std::move(obj1);  // 移动：允许
    
    return 0;
}
```

### 5.3 常见使用场景

```cpp
#include <memory>

// 1. 单例模式：禁止拷贝和移动
class Singleton {
private:
    static Singleton* instance;
    
    Singleton() = default;
    
public:
    Singleton(const Singleton&) = delete;
    Singleton& operator=(const Singleton&) = delete;
    Singleton(Singleton&&) = delete;
    Singleton& operator=(Singleton&&) = delete;
    
    static Singleton* getInstance() {
        if (!instance) {
            instance = new Singleton();
        }
        return instance;
    }
};

// 2. 接口类：只能通过指针使用
class Interface {
public:
    virtual ~Interface() = default;
    virtual void doSomething() = 0;
    
protected:
    Interface() = default;
    Interface(const Interface&) = delete;
    Interface& operator=(const Interface&) = delete;
};

// 3. 只能移动的资源
class UniqueResource {
private:
    std::unique_ptr<int> resource;
    
public:
    UniqueResource() : resource(std::make_unique<int>(0)) {}
    
    // 禁用拷贝
    UniqueResource(const UniqueResource&) = delete;
    UniqueResource& operator=(const UniqueResource&) = delete;
    
    // 默认移动
    UniqueResource(UniqueResource&&) = default;
    UniqueResource& operator=(UniqueResource&&) = default;
};
```

## 6. 三个法则的对比

### 6.1 对比表

| 特性 | 三法则 | 五法则 | 零法则 |
|------|--------|--------|--------|
| **适用场景** | C++98/03 | C++11+ | C++11+ 最佳实践 |
| **管理资源** | 手动管理 | 手动管理（含移动） | 使用 RAII 类型 |
| **特殊函数数量** | 3 个 | 5 个 | 0 个 |
| **性能** | 中等（拷贝） | 高（移动优化） | 高（移动优化） |
| **维护成本** | 中等 | 高 | 低 |
| **推荐度** | 传统代码 | 需要自定义资源管理 | 强烈推荐 |

### 6.2 决策树

```
需要管理资源？
    │
    ├─ 否 → 使用零法则（最佳）
    │      ↓
    │      使用 std::string、std::vector、std::unique_ptr 等
    │
    └─ 是 → 能用 RAII 封装吗？
           │
           ├─ 能 → 使用零法则
           │      ↓
           │      创建 RAII 包装类
           │
           └─ 不能 → 使用五法则
                  ↓
                  自定义所有五个特殊成员函数
```

### 6.3 完整示例对比

```cpp
#include <iostream>
#include <string>
#include <memory>
#include <cstring>

// === 三法则示例 ===
class RuleOfThree {
private:
    char* buffer;
    size_t size;
    
public:
    RuleOfThree(size_t n) : size(n) {
        buffer = new char[size];
    }
    
    ~RuleOfThree() {
        delete[] buffer;
    }
    
    RuleOfThree(const RuleOfThree& other) : size(other.size) {
        buffer = new char[size];
        memcpy(buffer, other.buffer, size);
    }
    
    RuleOfThree& operator=(const RuleOfThree& other) {
        if (this != &other) {
            delete[] buffer;
            size = other.size;
            buffer = new char[size];
            memcpy(buffer, other.buffer, size);
        }
        return *this;
    }
};

// === 五法则示例 ===
class RuleOfFive {
private:
    char* buffer;
    size_t size;
    
public:
    RuleOfFive(size_t n) : size(n) {
        buffer = new char[size];
    }
    
    ~RuleOfFive() {
        delete[] buffer;
    }
    
    RuleOfFive(const RuleOfFive& other) : size(other.size) {
        buffer = new char[size];
        memcpy(buffer, other.buffer, size);
    }
    
    RuleOfFive& operator=(const RuleOfFive& other) {
        if (this != &other) {
            delete[] buffer;
            size = other.size;
            buffer = new char[size];
            memcpy(buffer, other.buffer, size);
        }
        return *this;
```

## 8. 常见陷阱和最佳实践

### 8.1 陷阱1：忘记自赋值检查

```cpp
class MyClass {
private:
    int* data;
    
public:
    // ❌ 错误：没有自赋值检查
    MyClass& operator=(const MyClass& other) {
        delete data;  // 如果 this == &other，data 已被释放！
        data = new int(*other.data);  // 访问已释放的内存！
        return *this;
    }
    
    // ✅ 正确：添加自赋值检查
    MyClass& operator=(const MyClass& other) {
        if (this != &other) {
            delete data;
            data = new int(*other.data);
        }
        return *this;
    }
};
```

### 8.2 陷阱2：移动后忘记置空

```cpp
class MyClass {
private:
    int* data;
    
public:
    // ❌ 错误：没有置空源对象
    MyClass(MyClass&& other) noexcept : data(other.data) {
        // 忘记 other.data = nullptr;
    }
    
    ~MyClass() {
        delete data;  // 双重释放！
    }
    
    // ✅ 正确：置空源对象
    MyClass(MyClass&& other) noexcept : data(other.data) {
        other.data = nullptr;
    }
};
```

### 8.3 陷阱3：异常安全问题

```cpp
class MyClass {
private:
    int* data1;
    int* data2;
    
public:
    // ❌ 不安全：如果第二次分配失败，data1 泄漏
    MyClass& operator=(const MyClass& other) {
        if (this != &other) {
            delete data1;
            delete data2;
            data1 = new int(*other.data1);
            data2 = new int(*other.data2);  // 可能抛出异常！
        }
        return *this;
    }
    
    // ✅ 安全：使用 copy-and-swap 惯用法
    MyClass& operator=(const MyClass& other) {
        MyClass temp(other);  // 先拷贝
        swap(temp);           // 再交换（不抛异常）
        return *this;          // temp 析构释放旧资源
    }
    
    void swap(MyClass& other) noexcept {
        std::swap(data1, other.data1);
        std::swap(data2, other.data2);
    }
};
```

### 8.4 最佳实践总结

```cpp
// ✅ 最佳实践检查清单

class WellDesigned {
private:
    std::unique_ptr<int> resource;  // 1. 优先使用 RAII 类型
    
public:
    // 2. 如果不需要拷贝，显式禁用
    WellDesigned(const WellDesigned&) = delete;
    WellDesigned& operator=(const WellDesigned&) = delete;
    
    // 3. 移动操作标记 noexcept
    WellDesigned(WellDesigned&&) noexcept = default;
    WellDesigned& operator=(WellDesigned&&) noexcept = default;
    
    // 4. 析构函数通常应该是 noexcept
    ~WellDesigned() noexcept = default;
};

// 如果必须手动管理资源
class ManualResource {
private:
    int* data;
    
public:
    ManualResource() : data(nullptr) {}
    
    ~ManualResource() { delete data; }
    
    // 5. 拷贝操作：检查自赋值
    ManualResource(const ManualResource& other) {
        data = other.data ? new int(*other.data) : nullptr;
    }
    
    ManualResource& operator=(const ManualResource& other) {
        if (this != &other) {  // 自赋值检查
            delete data;
            data = other.data ? new int(*other.data) : nullptr;
        }
        return *this;
    }
    
    // 6. 移动操作：置空源对象，标记 noexcept
    ManualResource(ManualResource&& other) noexcept : data(other.data) {
        other.data = nullptr;
    }
    
    ManualResource& operator=(ManualResource&& other) noexcept {
        if (this != &other) {
            delete data;
            data = other.data;
            other.data = nullptr;
        }
        return *this;
    }
```

## 9. 知识点总结

| 概念 | 定义 | 关键点 |
|------|------|--------|
| **三法则** | 自定义析构/拷贝构造/拷贝赋值中的一个，需要全部自定义 | C++98/03 资源管理 |
| **五法则** | 三法则 + 移动构造 + 移动赋值 | C++11+ 完整资源管理 |
| **零法则** | 不自定义特殊成员函数，使用 RAII | 现代 C++ 最佳实践 |
| **= default** | 显式要求编译器生成默认实现 | 提高代码清晰度 |
| **= delete** | 显式禁止某个函数 | 防止意外使用 |
| **RAII** | 资源获取即初始化 | 自动资源管理 |
| **自赋值检查** | `if (this != &other)` | 防止资源被误释放 |
| **noexcept** | 声明不抛异常 | 移动操作必备 |

**核心要点：**

1. **优先级：零法则 > 五法则 > 三法则**
   - 尽量使用零法则（最简单、最安全）
   - 如果必须自定义，使用五法则（完整、高效）
   - 三法则是传统方式（不推荐新代码）

2. **设计原则**
   - 优先使用标准库 RAII 类型
   - 避免手动管理资源
   - 如果需要，封装成 RAII 类
   - 使用 `= delete` 明确禁止不需要的操作

3. **实现要点**
   - 拷贝操作：深拷贝，检查自赋值
   - 移动操作：转移资源，置空源对象，标记 `noexcept`
   - 析构函数：清理资源，应该是 `noexcept`

4. **何时使用何法则**
   - 不管理资源 → 零法则
   - 使用 RAII 封装 → 零法则
   - 必须手动管理 C 资源 → 五法则
   - 维护旧代码 → 三法则
