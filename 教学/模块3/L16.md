## 1. 左值与右值：概念基础

### 1.1 什么是左值和右值？

在 C++ 中，每个表达式都有两个属性：**类型（type）** 和 **值类别（value category）**。

**传统简化理解：**
- **左值（lvalue）**：可以出现在赋值表达式左侧的表达式，有名字，可以取地址
- **右值（rvalue）**：只能出现在赋值表达式右侧的表达式，临时对象，不能取地址

```cpp
#include <iostream>

int main() {
    int a = 10;      // a 是左值，10 是右值
    int b = 20;      // b 是左值，20 是右值
    
    int* p1 = &a;    // ✅ 可以取左值的地址
    // int* p2 = &10; // ❌ 错误：不能取右值的地址
    
    a = b;           // ✅ 左值可以被赋值
    // 10 = 20;      // ❌ 错误：右值不能被赋值
    
    int c = a + b;   // a + b 是右值表达式
    // (a + b) = 30; // ❌ 错误：不能给右值赋值
    
    return 0;
}
```

### 1.2 左值和右值的详细分类

C++11 引入了更精细的值类别划分：

```
表达式 (Expression)
├── 泛左值 (glvalue - Generalized lvalue)
│   ├── 左值 (lvalue)
│   └── 将亡值 (xvalue - eXpiring value)
└── 右值 (rvalue)
    ├── 将亡值 (xvalue)
    └── 纯右值 (prvalue - Pure rvalue)
```

**三种基本值类别：**

1. **左值（lvalue）**：有名字的变量、函数、左值引用返回的表达式
2. **纯右值（prvalue）**：字面量、临时对象、非引用返回的函数调用
3. **将亡值（xvalue）**：即将被移动的对象，如 `std::move()` 的返回值

```cpp
#include <iostream>
#include <vector>

int getValue() { return 42; }           // 返回右值
int& getRef() { static int x = 10; return x; }  // 返回左值

int main() {
    // === 左值示例 ===
    int a = 10;                // a 是左值
    int& ref = a;              // ref 是左值
    int* ptr = &a;             // 可以取地址
    
    // === 纯右值示例 ===
    int b = 42;                // 42 是纯右值
    int c = getValue();        // getValue() 返回纯右值
    int d = a + b;             // a + b 是纯右值
    
    // === 将亡值示例 ===
    std::vector<int> vec1 = {1, 2, 3};
    std::vector<int> vec2 = std::move(vec1);  // std::move(vec1) 是将亡值
    
    return 0;
}
```

### 1.3 判断左值和右值的经验法则

```cpp
#include <iostream>

int globalVar = 100;

int getValue() { return 42; }
int& getReference() { return globalVar; }
int&& getRvalueRef() { return 42; }

int main() {
    int x = 10;
    
    // ✅ 左值：有名字
    x;                  // 左值：变量名
    globalVar;          // 左值：全局变量
    getReference();     // 左值：返回左值引用的函数
    ++x;                // 左值：前置递增返回左值
    
    // ✅ 右值：临时对象或字面量
    10;                 // 右值：字面量
    x + 10;             // 右值：算术表达式结果
    getValue();         // 右值：返回非引用类型
    x++;                // 右值：后置递增返回临时对象
    
    // 🔍 判断技巧：能否取地址？
    int* p1 = &x;              // ✅ 可以
    // int* p2 = &(x + 10);    // ❌ 不可以，是右值
    // int* p3 = &getValue();  // ❌ 不可以，是右值
    int* p4 = &getReference(); // ✅ 可以，返回左值引用
    
    return 0;
}
```

## 2. 右值引用的语法

### 2.1 右值引用的声明

使用 `T&&` 声明右值引用，它只能绑定到右值：

```cpp
#include <iostream>

int main() {
    int x = 10;
    
    // === 左值引用 ===
    int& lref = x;         // ✅ 左值引用绑定到左值
    // int& lref2 = 10;    // ❌ 错误：左值引用不能绑定到右值
    const int& clref = 10; // ✅ const 左值引用可以绑定到右值
    
    // === 右值引用 ===
    int&& rref = 10;       // ✅ 右值引用绑定到右值
    int&& rref2 = x + 5;   // ✅ 右值引用绑定到临时对象
    // int&& rref3 = x;    // ❌ 错误：右值引用不能绑定到左值
    
    // ⚠️ 重要：右值引用本身是左值！
    int&& rref4 = 20;
    int& lref3 = rref4;    // ✅ 右值引用变量本身是左值
    
    std::cout << "rref4 = " << rref4 << std::endl;
    
    return 0;
}
```

### 2.2 引用类型总结表

| 声明类型 | 能绑定的值 | 示例 |
|----------|-----------|------|
| `T&` | 左值 | `int& ref = x;` |
| `const T&` | 左值 + 右值 | `const int& ref = 10;` |
| `T&&` | 右值 | `int&& ref = 10;` |
| `const T&&` | 右值（很少使用） | `const int&& ref = 10;` |

```cpp
#include <iostream>
#include <string>

void processLvalue(int& x) {
    std::cout << "左值引用: " << x << std::endl;
}

void processRvalue(int&& x) {
    std::cout << "右值引用: " << x << std::endl;
}

void processConst(const int& x) {
    std::cout << "const 左值引用（万能引用）: " << x << std::endl;
}

int main() {
    int a = 10;
    
    processLvalue(a);        // ✅ 左值
    // processLvalue(20);    // ❌ 不能绑定右值
    
    // processRvalue(a);     // ❌ 不能绑定左值
    processRvalue(20);       // ✅ 右值
    processRvalue(a + 10);   // ✅ 右值
    
    processConst(a);         // ✅ 可以绑定左值
    processConst(30);        // ✅ 可以绑定右值
    
    return 0;
}
```

### 2.3 右值引用的生命周期延长

右值引用和 const 左值引用都可以延长临时对象的生命周期：

```cpp
#include <iostream>
#include <string>

std::string getString() {
    return "Hello, World!";
}

int main() {
    // ❌ 危险：临时对象立即销毁
    // const char* p = getString().c_str();  // 悬空指针！
    
    // ✅ 生命周期延长：临时对象在引用作用域内有效
    const std::string& ref1 = getString();
    std::cout << ref1 << std::endl;  // 安全
    
    // ✅ 右值引用也能延长生命周期
    std::string&& ref2 = getString();
    std::cout << ref2 << std::endl;  // 安全
    
    // ref1 和 ref2 销毁时，临时对象才销毁
    return 0;
}
```

## 3. 右值引用的核心价值：避免拷贝

### 3.1 拷贝的性能问题

```cpp
#include <iostream>
#include <vector>
#include <cstring>

class BigData {
private:
    int* data;
    size_t size;
    
public:
    // 构造函数
    BigData(size_t n) : size(n) {
        data = new int[size];
        std::cout << "构造 BigData，分配 " << size << " 个整数
";
    }
    
    // 拷贝构造函数：深拷贝，开销大
    BigData(const BigData& other) : size(other.size) {
        data = new int[size];
        std::memcpy(data, other.data, size * sizeof(int));
        std::cout << "拷贝构造 BigData，拷贝 " << size << " 个整数
";
    }
    
    // 析构函数
    ~BigData() {
        delete[] data;
        std::cout << "析构 BigData
";
    }
    
    void print() const {
        std::cout << "BigData 包含 " << size << " 个整数
";
    }
};

BigData createBigData() {
    return BigData(1000000);  // 返回临时对象
}

int main() {
    std::cout << "=== 使用拷贝构造 ===
";
    BigData data1 = createBigData();  // 可能触发拷贝
    data1.print();
    
    return 0;
}
```

**问题：** 当 `createBigData()` 返回时，临时对象会被拷贝到 `data1`，造成：
1. 额外的内存分配
2. 数据拷贝开销
3. 临时对象的销毁

### 3.2 右值引用接管资源

虽然现在还不能直接使用移动构造（下节课内容），但我们可以看到右值引用如何标识临时对象：

```cpp
#include <iostream>

class Resource {
private:
    int* data;
    
public:
    Resource(int value) {
        data = new int(value);
        std::cout << "构造资源，地址: " << data << std::endl;
    }
    
    // 接受右值引用的函数
    void acquire(int&& temp) {
        std::cout << "接收到右值: " << temp << std::endl;
        // 这里可以"窃取"资源，而不是拷贝
    }
    
    ~Resource() {
        delete data;
        std::cout << "销毁资源
";
    }
};

int getValue() {
    return 42;
}

int main() {
    Resource res(100);
    
    // 传递右值
    res.acquire(10);           // 字面量
    res.acquire(getValue());   // 函数返回值
    res.acquire(5 + 3);        // 表达式结果
    
    return 0;
}
```

## 4. 函数重载与值类别

### 4.1 基于引用类型的重载

可以基于左值引用和右值引用重载函数：

```cpp
#include <iostream>
#include <string>

void process(int& x) {
    std::cout << "处理左值: " << x << std::endl;
}

void process(int&& x) {
    std::cout << "处理右值: " << x << std::endl;
}

int main() {
    int a = 10;
    
    process(a);        // 调用 process(int&)
    process(20);       // 调用 process(int&&)
    process(a + 5);    // 调用 process(int&&)
    
    return 0;
}
```

### 4.2 完美转发的预备知识

```cpp
#include <iostream>
#include <string>

class Printer {
public:
    void print(const std::string& str) {
        std::cout << "打印左值: " << str << std::endl;
    }
    
    void print(std::string&& str) {
        std::cout << "打印右值: " << str << std::endl;
    }
};

template<typename T>
void forwardPrint(Printer& printer, T&& value) {
    // 注意：value 作为参数是左值！
    printer.print(value);  // 总是调用 print(const std::string&)
}

int main() {
    Printer p;
    std::string str = "Hello";
    
    // 直接调用
    p.print(str);              // 打印左值
    p.print("World");          // 打印右值
    
    std::cout << "--- 通过模板转发 ---
";
    // 通过模板转发
    forwardPrint(p, str);      // 期望调用左值版本
    forwardPrint(p, "Test");   // 期望调用右值版本，但实际调用左值版本！
    
    return 0;
}
```

**问题：** 即使传递右值给 `forwardPrint`，`value` 参数本身是左值，导致总是调用左值版本。（完美转发会在后续课程解决这个问题）

## 5. 引用折叠规则

### 5.1 引用折叠的基本规则

在模板和类型推导中，引用可能会"叠加"，C++ 使用引用折叠规则处理：

**规则：**
- `T& &` → `T&`
- `T& &&` → `T&`
- `T&& &` → `T&`
- `T&& &&` → `T&&`

**简记：** 只有 `T&& &&` 折叠为 `T&&`，其他都折叠为 `T&`

```cpp
#include <iostream>

template<typename T>
void checkType(T&& param) {
    std::cout << "接收到参数
";
}

int main() {
    int x = 10;
    
    checkType(x);     // T 推导为 int&，param 类型为 int& && → int&
    checkType(20);    // T 推导为 int，param 类型为 int&&
    
    return 0;
}
```

### 5.2 万能引用（Universal Reference）

在模板参数推导中，`T&&` 有特殊含义，被称为"万能引用"或"转发引用"：

```cpp
#include <iostream>
#include <string>

template<typename T>
void universal(T&& param) {
    std::cout << "接收到参数
";
}

void specific(int&& param) {
    std::cout << "只接受右值
";
}

int main() {
    int x = 10;
    
    // T&& 在模板中是万能引用，可以绑定左值和右值
    universal(x);        // ✅ 绑定左值，T = int&
    universal(20);       // ✅ 绑定右值，T = int
    
    // int&& 不是模板，只能绑定右值
    // specific(x);      // ❌ 错误
    specific(30);        // ✅ 正确
    
    return 0;
}
```

**重要区别：**
- `T&&` 在模板中 = 万能引用（可以绑定左值和右值）
- `int&&` 不在模板中 = 纯右值引用（只能绑定右值）

## 6. std::move 初探

### 6.1 std::move 的作用

`std::move` 不移动任何东西，它只是将左值转换为右值引用：

```cpp
#include <iostream>
#include <utility>

void process(int& x) {
    std::cout << "处理左值: " << x << std::endl;
}

void process(int&& x) {
    std::cout << "处理右值: " << x << std::endl;
}

int main() {
    int a = 10;
    
    process(a);              // 调用左值版本
    process(std::move(a));   // 调用右值版本
    
    // ⚠️ 注意：a 仍然有效，但处于"有效但未指定"状态
    std::cout << "a 的值: " << a << std::endl;  // 仍然是 10（对于 int）
    
    return 0;
}
```

### 6.2 std::move 的实现原理

`std::move` 的简化实现：

```cpp
template<typename T>
typename std::remove_reference<T>::type&& move(T&& param) {
    return static_cast<typename std::remove_reference<T>::type&&>(param);
}
```

它只是进行类型转换，没有任何运行时操作。

### 6.3 std::move 的使用示例

```cpp
#include <iostream>
#include <vector>
#include <string>

int main() {
    std::vector<int> vec1 = {1, 2, 3, 4, 5};
    
    std::cout << "vec1 大小: " << vec1.size() << std::endl;
    
    // 使用 std::move 将 vec1 转换为右值
    std::vector<int> vec2 = std::move(vec1);
    
    std::cout << "移动后：
";
    std::cout << "vec1 大小: " << vec1.size() << std::endl;  // 0（被移空）
    std::cout << "vec2 大小: " << vec2.size() << std::endl;  // 5
    
    // ⚠️ vec1 仍然可用，但内容未指定
    vec1.push_back(100);  // 可以继续使用
    std::cout << "vec1 新大小: " << vec1.size() << std::endl;
    
    return 0;
}
```

## 7. 右值引用的常见误区

### 7.1 误区1：右值引用参数是右值

```cpp
#include <iostream>

void func(int&& x) {
    // x 是右值引用，但 x 本身是左值！
    int& lref = x;       // ✅ 可以绑定
    // int&& rref = x;   // ❌ 错误
    
    std::cout << "x = " << x << std::endl;
}

int main() {
    func(10);
    return 0;
}
```

**关键点：** 右值引用**变量**本身是左值，只有**右值引用表达式**可能是右值。

### 7.2 误区2：std::move 真的移动了对象

```cpp
#include <iostream>

int main() {
    int a = 10;
    int b = std::move(a);  // 实际上是拷贝，不是移动（int 没有移动语义）
    
    std::cout << "a = " << a << std::endl;  // 10
    std::cout << "b = " << b << std::endl;  // 10
    
    // std::move 只是类型转换，不改变值
    return 0;
}
```

### 7.3 误区3：移动后的对象不能使用

```cpp
#include <iostream>
#include <vector>

int main() {
    std::vector<int> vec1 = {1, 2, 3};
    std::vector<int> vec2 = std::move(vec1);
    
    // ✅ 可以继续使用 vec1，但内容未指定
    std::cout << "vec1 是否为空: " << vec1.empty() << std::endl;
    
    // ✅ 可以重新赋值
    vec1 = {10, 20, 30};
    std::cout << "vec1 大小: " << vec1.size() << std::endl;
    
    return 0;
}
```

**正确理解：** 移动后的对象处于"有效但未指定"状态，可以：
- 销毁
- 重新赋值
- 调用不依赖当前状态的操作

但不应该：
- 访问其值（除非重新赋值）
- 假设它处于特定状态

## 8. 实际应用场景

### 8.1 返回大对象

```cpp
#include <iostream>
#include <vector>

// 返回大容器（现代编译器会自动优化）
std::vector<int> createLargeVector(size_t n) {
    std::vector<int> vec;
    vec.reserve(n);
    for (size_t i = 0; i < n; ++i) {
        vec.push_back(i);
    }
    return vec;  // 编译器会优化为移动或 RVO
}

int main() {
    std::vector<int> data = createLargeVector(1000000);
    std::cout << "数据大小: " << data.size() << std::endl;
    return 0;
}
```

### 8.2 容器插入优化

```cpp
#include <iostream>
#include <vector>
#include <string>

int main() {
    std::vector<std::string> words;
    
    std::string temp = "Hello";
    
    // 拷贝插入
    words.push_back(temp);           // temp 被拷贝
    std::cout << "temp 仍然有效: " << temp << std::endl;
    
    // 移动插入
    words.push_back(std::move(temp)); // temp 被移动
    std::cout << "temp 被移动，内容: "" << temp << """ << std::endl;
    
    // 直接构造（emplace）
    words.emplace_back("World");     // 原地构造，最高效
    
    for (const auto& word : words) {
        std::cout << word << " ";
    }
    std::cout << std::endl;
    
    return 0;
}
```

### 8.3 交换两个对象

```cpp
#include <iostream>
#include <utility>
#include <vector>

template<typename T>
void mySwap(T& a, T& b) {
    T temp = std::move(a);  // 移动而非拷贝
    a = std::move(b);
    b = std::move(temp);
}

int main() {
    std::vector<int> vec1 = {1, 2, 3};
    std::vector<int> vec2 = {4, 5, 6, 7, 8};
    
    std::cout << "交换前：
";
    std::cout << "vec1 大小: " << vec1.size() << std::endl;
    std::cout << "vec2 大小: " << vec2.size() << std::endl;
    
    mySwap(vec1, vec2);
    
    std::cout << "交换后：
";
    std::cout << "vec1 大小: " << vec1.size() << std::endl;
    std::cout << "vec2 大小: " << vec2.size() << std::endl;
    
    return 0;
}
```

## 9. 完整实战案例：字符串缓冲区管理

```cpp
#include <iostream>
#include <cstring>
#include <utility>

class StringBuffer {
private:
    char* buffer;
    size_t capacity;
    size_t length;
    
public:
    // 构造函数
    StringBuffer(const char* str = "") {
        length = std::strlen(str);
        capacity = length + 1;
        buffer = new char[capacity];
        std::strcpy(buffer, str);
        std::cout << "[构造] 分配 " << capacity << " 字节，内容: "" 
                  << buffer << ""
";
    }
    
    // 拷贝构造函数
    StringBuffer(const StringBuffer& other) {
        length = other.length;
        capacity = other.capacity;
        buffer = new char[capacity];
        std::strcpy(buffer, other.buffer);
        std::cout << "[拷贝构造] 分配 " << capacity << " 字节，拷贝内容: "" 
                  << buffer << ""
";
    }
    
    // 拷贝赋值运算符
    StringBuffer& operator=(const StringBuffer& other) {
        if (this != &other) {
            delete[] buffer;
            length = other.length;
            capacity = other.capacity;
            buffer = new char[capacity];
            std::strcpy(buffer, other.buffer);
            std::cout << "[拷贝赋值] 分配 " << capacity << " 字节，拷贝内容: "" 
                      << buffer << ""
";
        }
        return *this;
    }
    
    // 析构函数
    ~StringBuffer() {
        std::cout << "[析构] 释放缓冲区，内容: "" << (buffer ? buffer : "null") << ""
";
        delete[] buffer;
    }
    
    // 获取内容
    const char* c_str() const { return buffer; }
    size_t size() const { return length; }
    
    // 追加内容
    void append(const char* str) {
        size_t addLen = std::strlen(str);
        if (length + addLen + 1 > capacity) {
            // 扩容
            capacity = (length + addLen + 1) * 2;
            char* newBuffer = new char[capacity];
            std::strcpy(newBuffer, buffer);
            delete[] buffer;
            buffer = newBuffer;
        }
        std::strcat(buffer, str);
        length += addLen;
    }
};

// 创建临时缓冲区（返回右值）

    return StringBuffer(content);
}

    std::cout << ">>> 处理左值缓冲区: "" << buf.c_str() << ""
";
}

// 处理右值引用

    std::cout << ">>> 处理右值缓冲区（临时对象）: "" << buf.c_str() << ""
";
    // 这里可以安全地"窃取"资源（下节课会学习移动构造）
}

";
    StringBuffer buf1("Hello");
    processLvalue(buf1);                    // 调用左值版本
    processRvalue(createBuffer("World"));   // 调用右值版本
    
    std::cout << "
=== 测试2：拷贝的开销 ===
";
    StringBuffer buf2("First");
    StringBuffer buf3 = buf2;               // 拷贝构造
    buf3.append(" Second");
    StringBuffer buf4("Temp");
    buf4 = buf2;                            // 拷贝赋值
    
    std::cout << "

";
    StringBuffer buf5("Original");

";
```

## 10. 知识点总结

| 概念 | 说明 | 关键点 |
|------|------|--------|
| **左值（lvalue）** | 有名字的对象，可以取地址 | 变量、引用、解引用指针 |
| **右值（rvalue）** | 临时对象，不能取地址 | 字面量、临时对象、表达式结果 |
| **纯右值（prvalue）** | 传统意义的右值 | 字面量、非引用返回值 |
| **将亡值（xvalue）** | 即将被移动的对象 | `std::move()` 的结果 |
| **右值引用（T&&）** | 绑定到右值的引用 | 可以延长临时对象生命周期 |
| **引用折叠** | `&&` 遇到 `&&` 才是 `&&`，其他都是 `&` | 用于模板推导 |
| **万能引用** | 模板中的 `T&&` | 可以绑定左值和右值 |
| **std::move** | 将左值转换为右值引用 | 只是类型转换，不移动任何东西 |

**核心要点：**

1. **值类别的本质**
   - 左值有身份（identity），可以取地址
   - 右值是临时的，生命周期短暂
   - 将亡值是特殊的右值，表示可以被"窃取"资源

2. **右值引用的意义**
   - 区分对象是否临时
   - 允许"移动"而非"拷贝"
   - 提高性能，减少不必要的拷贝

3. **重要规则**
   - 右值引用变量本身是左值
   - `std::move` 不移动，只转换类型
   - 移动后对象仍可用，但状态未指定

4. **使用场景**
   - 返回大对象
   - 容器插入优化
   - 对象交换
   - 资源管理
